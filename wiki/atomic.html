按六层拆解界面：Tokens → Atoms → Molecules → Organisms → Templates → Pages。前四层的控件都是真实渲染（直接用 tokens 拼出来，不是示意图），Templates 与 Pages 两层给出每屏的栏位骨架与组成。全篇不依赖其它文件即可阅读；令牌数值的完整定义见 DESIGN.md，实现取值见 src/web/src/styles/tokens.css。

本版对照 DESIGN.md v1.9（2026-11-03：标题位统一为界面字体／黑体）与实现 0.1.18（2026-11-03）补齐：侧栏三段重做、回看三格、待整理两格、加密空间独立成行、主题树连接线与展开箭头、段标题 11/500/faint、页脚连接状态点；属性区只读/编辑两态、设置面板九分区、主题三档切换、表格网格线、图片上传进度、AI 概述、Memo 评论/收藏/引述。两者不一致时以 DESIGN.md 为准并回改本文件。

新组件往哪放，三轮问完
判定顺序自上而下，先命中先归属
  1. 只吃 token、不含业务语义 → src/web/src/components/ui
  2. 含业务语义、只服务一个 feature → src/web/src/features/<x>
  3. 跨 feature 复用且含业务语义 → 提升到该 feature 的公共入口 index.ts
  4. 只服务外壳装配（侧栏、首页、账户菜单、移动壳） → src/web/src/app

不判定「算分子还是有机体」——边界主观，争论没有产出。
