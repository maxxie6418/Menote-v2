06

归属判定

新组件往哪放，三轮问完
判定顺序自上而下，先命中先归属
  1. 只吃 token、不含业务语义 → components/ui
  2. 含业务语义、只服务一个 feature → features/<x>/components
  3. 跨 feature 复用且含业务语义 → 提升到该 feature 的公共入口 index.ts

不判定「算分子还是有机体」——边界主观，争论没有产出。

状态穷举准入条件，不是加分项
组件必须覆盖
按钮default / hover / focus / active / disabled / loading
输入框default / focus / error / disabled / readonly
