# Menote V2 移动端设计（v0.1）

- **文档状态**：设计基线 v0.1（2026-11-01）。可视化预览见 `wiki/mobile.html`（同目录，九屏可交互查看深浅两套令牌）。
- **适用范围**：手机竖屏，基准 375×812。平板、横屏、折叠屏不在本文范围。
- **上游依据**：`DESIGN.md`（视觉令牌与选择态）、`Menote_V2_需求说明书_v1.2.md`（FR-IA / FR-MEMO / FR-EDT / FR-PROP / FR-ENC）、`AGENTS.md`（工程纪律）。冲突时：功能以需求说明书为准，视觉以 `DESIGN.md` 为准，移动端特有形态以本文为准。
- **文档定位**：`DESIGN.md` §8.1 只写到「< 768 单栏 + 底部主导航 + 触控 ≥ 44px」，未定义输入形态与导航层级。本文补的正是这一层。

---

## 1. 定位与三条原则

**移动端不是主输入端。** 它承担两件事：

1. **接替**：桌面端没做完的内容，在手机上继续看、继续改。
2. **速记**：临时记下一点东西，回桌面再完整处理。

由此推出全部形态取舍。**查阅是主力**，输入是低频但有即时性需求的动作。

| 原则 | 含义 | 落到界面 |
| --- | --- | --- |
| 内容占满屏 | 除导航外不设常驻控件 | 不设顶部记录条；滚动时顶栏隐去；清单无卡片包裹 |
| 输入不占位 | 输入只在被叫出时存在 | 唯一入口是底部记录键，44px，不越界到内容区 |
| 一个位置、一个方向 | 入口与面板同向同处 | 键在底部中央，面板从底部升起；不做「上点下弹」 |

**关键取舍**：Plan A 曾在首页与 Memo 顶部各放一条 40px 记录条。它的形态是输入框（有占位符、有光标暗示），行为却是按钮（点开从底部弹面板），且「不吸顶」——滚到中部想记一笔要先滑回顶部，与「临时速记」直接冲突。Plan B 删除该控件，改为底部记录键。

## 2. 信息架构

```
底部导航（5 格，各 75px）
├─ 首页      概览：收藏 / 最近 / 待整理
├─ Memo      时间线：全部 / 待办 / 图册
├─ 记录键    唯一输入入口（44px 橙面圆钮，非 tab）
├─ 笔记      主题聚合清单 → 文档
└─ 我的      账号、数据概览、设置
```

- 记录键不占 tab 语义，点击弹面板，不切换页面，因此不高亮。
- 主题树不在一级导航内，从笔记清单顶部的「主题名 ⌄」进入全屏抽屉。
- 设置与账号全部集中在「我的」，抽屉不再兼设置。

### 2.1 输入入口的三种放法与选型

| 放法 | 误触来源 | 结论 |
| --- | --- | --- |
| 凸出型 52px（圆钮高出导航 17px） | 三分之一压在内容区，滚动、翻列表、滑动返回都会划过；正中又是拇指休息位 | 否 |
| **内嵌型 44px（采用）** | 只剩导航区手势，与点相邻 tab 同级；左右各留 15px，斜滑不易带过 | **采用** |
| 右下悬浮 52px | 避开正中，但长列表最后一条右下角被压 | 否 |
| 顶栏「＋」 | 几乎不误触 | 否，入口在上、面板在下，方向相反 |

兜底交互：**按下不算数，抬手才算**。按住时圆钮缩至 0.96 并加深，手指移出 44px 范围即取消、不弹面板。

## 3. 屏幕清单

九屏，对应 `mobile.html` 的 01–09。

| # | 屏幕 | 承担 | 关键规格 |
| --- | --- | --- | --- |
| 01 | 首页 | 回看 | 收藏（横滑卡 150 宽）+ 最近（44px 行）+ 底部 dock「收件箱 / 草稿箱」 |
| 02 | Memo | 时间线 | 无顶栏滚动态；筛选行 38px 吸顶；条目 3 行折叠 |
| 03 | 写入面板 · Memo | 速记 | 半屏 top 150；等宽源文本 13/1.75 |
| 04 | 写入面板 · 笔记 | 长文 | 全屏 top 30；标题 24 无衬线；正文 15/1.75 |
| 05 | 笔记清单 | 主题聚合 | 行高 64；顶部「主题名 ⌄」+「＋」 |
| 06 | 文档 | 阅读 / 编辑 | 属性折叠一行 34px；标题 24；正文 15；选中工具条贴底 |
| 07 | 主题抽屉 | 主题导航 | 全屏 sheet；树 44px 行；私人空间独立成段 |
| 08 | 我的 | 账号与配置 | 数据概览四格；设置六项；版本 |
| 09 | 已存条目 | 事后整理 | 长按动作面板：状态三选 / 加标签 / 删除 |

### 3.1 首页

从上到下：顶栏（品牌 + 搜索）→ 收藏（横滑 150 宽卡片）→ 最近（44px 单行，右侧日期）→ **dock：收件箱 / 草稿箱**。

- dock 固定在底部导航之上、不随内容滚动，是「接续未完成」的动作区，拇指一伸可及。
- dock 用中性灰底 + 橙色计数，不用淡橙成面：两块 48px 的橙面会占到全屏 10% 以上，违反 `DESIGN.md` §2.5 的橙色用量。
- 最近列表不做类型分组，靠 13px 线性图标区分 Note / Memo。

### 3.2 Memo

- **滚动态无顶栏**：状态栏下方直接是筛选行，可视内容从 820 提到 860。
- **筛选行吸顶**，38px：`全部 / 待办 5 / 图册 24`，当前项 2px 橙短线。它是查阅控件，与「输入控件不常驻」不冲突。
- 「待办」内部再分 **待办 / 进行中 / 已完成** 三组（组标题 26px + 计数），状态是分组不是筛选项——避免四个平级 chip。
- **「图册」接 FR-MEMO-6 的图片瀑布流**（2026-11-01 补出完整设计，原为占位入口）：
  - **2 列**，不是 3 列。375 宽减边距后每列约 165px，3 列会压到 100px 以下，认不出素材内容。
  - **按原始宽高比落位，不裁切**。图高随原图走，列高自然不等——这正是瀑布流的形态；裁切会让人认不出自己的图。
  - **懒加载占位保比例**：未进视口的图只画骨架，但占位高度按原比例预留，滚动时不跳版。
  - **点图回原条目**：图册不是独立图库，点任一张回到它所属的 Memo 原位；状态与标签仍在原条目里改。
  - **加密条目整体不出现**：私人空间与单篇加密 Memo 的附件按可见性谓词排除，不做缩略图缓存。
  - 每图下方保留来源 Memo 的时间（10 mono）与标签胶囊。
  - 完整设计见 `wiki/mobile.html` 第 10 屏与 DESIGN.md §4.5。
- 条目：满宽发丝线分隔，正文 13.5/1.7 最多 3 行，图片缩略 60×60，元信息行含时间（10 mono）、标签胶囊、状态胶囊。

### 3.3 写入面板

**两种形态，一个切换器。**

| | Memo | 笔记 |
| --- | --- | --- |
| 高度 | 半屏，top 150，底部贴键盘上沿 | 全屏，top 30 |
| 正文 | 等宽源文本 13/1.75（所见即源码） | 15/1.75 排版 |
| 标题 | 无 | 24 无衬线，可空 |
| 工具条 | 附件 / 标签 / 任务 | H2 · B · I · A ｜ # 标签 · 图片 |
| 去向 | → 时间线 | → 草稿箱 |
| 保存 | 落时间线今天 | 落草稿箱，用户自行移入主题 |

**头部三段**：左「取消」、正中 `Memo | 笔记` 切换器、右「保存」。切换器取代原先的「新记录 / 新笔记」标题文字——写的是什么，标题就写什么，不再多占一行。左右按钮各 `min-width:56px`，否则切换器会因两侧不等宽而视觉偏移。

**切换规则**：

- 已输入内容整体转成正文，标题留空由用户填。**不做「首行自动提标题」**——猜错比手动填更烦。
- 反向切回 Memo：标题并入正文首行，其余段落保留。
- 笔记默认落草稿箱，手机端不追问主题归属（FR-IA-6「先写再分类」）。

**身份边界**：形态只在编辑中选，已存内容不做 Memo ↔ Note 转换（FR-IA-9 守的是后者）。

### 3.4 笔记清单与文档

- 顶部只留一个变量：当前主题名 + 下拉箭头（进抽屉），右侧「＋」直接新建。
- 行高 64：标题 13.5/600 单行 + 摘要 12 单行 + 右侧日期 10 mono。加密笔记只多一枚 11px 锁标，不改行结构（FR-ENC-5 标题明文）。
- 文档页：属性折叠成一行 34px（状态 / 标签 / 更新），末尾箭头进全量属性；空文档不铺空行（FR-PROP-2）。
- 选中工具条从纸面底部浮出（通栏 40px，七个动作等分），**贴底而非压字**，避免遮挡正在改的那一段。

### 3.5 我的

账号行 → 同步指标行（待上传 / 云端 / 备份）→ **数据概览四格**（笔记 / Memo / 附件 / 本周）→ 内容（私人空间、标签）→ 设置六项 → 版本。

- 指标行回答同步状态，概览回答存量，两者不合并。
- 私人空间放在内容组而非主题树：它是加密作用域，不是目录节点；右侧只写「锁定」，不显示条目数，避免侧信道。
- 设置组内「资源状态」一行进入资源监控（详见 `Menote_V2_资源监控设计_v0.1.md`、`monitor.html`），右侧直接显示当前费用状态，不必点进去才知道。

## 4. 交互细则

| 场景 | 行为 |
| --- | --- |
| 点记录键 | 弹出半屏 Memo 面板，键盘同时唤醒，光标就位 |
| 切到笔记 | 面板原地「长高」成全屏，切换器位置不动，内容不丢 |
| 保存 | 存并退出，不弹 toast、不跳页；Memo 落时间线原位置 |
| 取消 / 下拉抓手 | 关闭面板，未发出的草稿留在本地；下次点键续写 |
| 长按条目 | 动作面板：状态三选、加标签、删除、取消 |
| 删除 | 不二次确认，给 8 秒撤销条（`DESIGN.md` §8.3） |
| 滚动 | 顶栏隐去，筛选行吸顶；记录键位置不变 |
| 保存笔记后 | 落草稿箱，不提示去归类 |

## 8. 视觉令牌

沿用 `src/web/src/styles/tokens.css` 的 `--app-*` / `--md-*`。移动端只新增两处取值：

- `正文 15px`（桌面 14）——阅读距离更远，14 偏小。
- `文档标题 24px`（桌面 32）——32 在 375 宽会占到五行。

> **注意**：这两项超出 `DESIGN.md` §3.2 的档位表（10 / 10.5 / 11.5 / 12 / 12.5 / 13.5 / 14 / 16 / 17 / 32）。若不允许新增档位，回落到 14 / 32 即可，其余结构不受影响；但正文 14 在手机上偏小，建议保留 15。

阴影：全页只有写入面板一层（圆角 + 1px 边框 + `0 -8px 24px rgba(26,26,24,.08)`）。列表、卡片、按钮均不加阴影，与 `DESIGN.md` §6 一致。
