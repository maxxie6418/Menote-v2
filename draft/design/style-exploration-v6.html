Menote V2 · Direction 06 · 2026-10-31

三个区域，三种密度

上一版把"轻"做到了极致，代价是把扫描性也一起减掉了：清单没有分隔、没有分组、没有可锚定的左缘，眼睛只能一行行比； 侧栏和清单又共用同一套视觉语言，三个区域挤成一个平面。

这一版按信息设计的基本顺序重做——先分区（三种密度、三种语言），再给清单加扫描线（分隔、分组、类型锚点）， 最后把品牌色放回该在的位置：主操作按钮、未读计数、当前状态、当前选中项。#F6821F 的实色面积约 0.7%，浅橙底约 2%，但每一处都在回答"你要看这里"。

01

三个区域，三种密度

格式塔·共同区域

同一屏里的并列区域，必须在一个维度上明显不同，否则会被读成一类东西。这里用底色、密度、图标三件事同时拉开。

区域承担什么视觉语言
侧栏导航与结构灰底 #F1F1EE、行高 30、12px、图标驱动、无摘要
笔记清单定位与比较白底、行高 60、13.5px/600、有分隔线与分组、带类型图标
文档阅读与写作白底大留白、衬线 30px 标题、正文 14px、无图标
侧栏为什么加深#F7F7F5 和白色只差一档，缩略图里几乎看不出分区。改到 #F1F1EE 后，侧栏在灰度上后退，白色主区自然成为工作区——这是 Notion、Bear、Things 共用的做法。
侧栏选中项换语言清单用"淡橙底 + 3px 橙条"，侧栏用"白底浮起 + 2px 橙条"。同一个"选中"概念，两个区域用不同处理，才不会混。
02

清单的扫描线

分隔 · 分组 · 锚点

列表的阅读成本不来自留白，来自"每一行的起点在哪里"。三件事解决它：一条横线定行，一个分组定段，一个左图标定起点。

手段v5v6
行分隔无，靠留白1px 线，从 40px 处起（避开图标列）
分组无，10 条连排「最近 / 更早」两组，组标题带延展线
左锚点无14px 类型图标：笔记 / 加密 / 表格
标题13px / 50013.5px / 600，与摘要拉开一个字重
选中态灰底 + 2px 橙条淡橙底 #FDF3EA + 3px 橙条
行内操作⋯ 悬停出现取消常驻位，改为右键／选中后工具栏
为什么分隔线从 40px 起如果横线顶到左边，它会把图标和标题隔断，读起来像表格。缩进到图标右侧，线只在"内容区"里起作用，分组感更强。
为什么撤掉行内 ⋯静态列表里常驻三个点会干扰扫描，而悬停才出现又要求用户先找到它。列表的批量操作交给多选后的工具栏，单行操作交给右键——这是效率更高的分配。
03

品牌色回归

从标记到主操作

上一版为了让画面安静，把橙砍到只剩几个点，结果是产品没有倾向。品牌色不该只做标记，它应该出现在"我要你注意这里"的位置。

位置v5v6
主按钮墨色实心橙底 #F6821F + 深字（7.2:1）
未读计数灰色数字橙色浅底胶囊
状态值文字前一个 5px 点完整胶囊 #FEF2E7 / #B4530F
列表选中灰底淡橙底 + 3px 橙条
侧栏选中灰底 + 点白底浮起 + 2px 橙条
Memo 输入纯文字提示前置 5px 橙点，暗示"这是一条快速记录"
橙色仍然不写字#F6821F 在纯白上 2.5:1，所以按钮上是深色字、胶囊里是 #B4530F 深橙字。品牌色可以扩面积，但不能扩到承担正文可读性。
蓝色链接我保留了你说"主题色别砍太多"我照做，但链接仍然留蓝：橙色一旦兼任品牌与链接，用户会分不清"这是品牌强调"还是"这能点"。这一条我建议保持。
04

浅色

灰侧栏 · 白清单 · 白文档

侧栏退成灰面，清单靠分隔线与分组形成"表"，文档靠留白与衬线形成"页"。三块一眼可分。

主区 #FFFFFF 侧栏 #F1F1EE 选中 #FDF3EA 橙浅层 #FEF2E7 橙 #F6821F 墨 #1A1A18 链接 #0051C3 行高 60 / 30
清单读起来像"表"行线 + 分组标题 + 左图标列，三者一起把清单从"一堆文字"变成"一张可扫的表"。这是这一版最大的收益。
侧栏的密度差侧栏 30px 行、12px 字；清单 60px 行、13.5px 字。密度差本身就是分区信号，不需要再加边框。
05

深色

冷炭底 · 侧栏再退一档

深色下"后退"靠压暗：侧栏 #131518 比主区 #1A1C1E 更沉。选中块用暖褐 #2B2118 承接橙色，这是唯一允许出现的暖色块。

主区 #1A1C1E 侧栏 #131518 选中 #2B2118 橙浅层 #3A2716 橙 #F6821F 墨 #E9EBED 链接 #7FA8FF 行高 60 / 30
深色的选中底橙色 8% 直接叠在冷炭上会发灰，改用预调过的暖褐 #2B2118，再配 3px 纯橙条，读起来才是"被选中"而不是"脏了一块"。
按钮不变深色下橙底深字仍然是全屏最亮的一块，这是对的——主操作在任何主题里都该最先被看到。
先分区，再划线，最后上色。
