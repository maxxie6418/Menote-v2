Menote V2 · Direction 03 · 2026-10-31

把剂量减下来，不是换风格

v2 的问题不在配色，在剂量：参考页的 1.5px 边框被我铺到了九个容器上，又叠了卡片底色和投影—— 三种分隔手段同时出现，任何界面都会重。v3 只守一条规则：每个地方只留一种分隔手段。 参考页的识别特征一个没丢：衬线标题、等宽小标签、纸面、留白。

减法清单

八处，都是可量化的

每一项都能说出「去掉了什么」和「为什么它本来不必存在」，不是把颜色调淡了事。

项目v2v3为什么
容器边框 9 处 · 1.5px 0 处容器边框
只有 3 条 1px 发丝线		 边框同时干了「分隔」和「强调」两件事，混在一起就重。强调交给选中态，分隔交给线。
卡片与投影 卡片 14px 圆角 + 0 10 30 阴影 无卡片、无阴影 在纸面主题里，投影是最重的信号——它暗示「这块浮起来了」，而三个等权重的面板本来没有高低。
主按钮 实心橙 + 墨字 1px 描边 + 墨字 实心橙是屏幕上面积最大的一块颜色，抢走了「当前文档」的注意力。参考页的入口本来就是描边胶囊。
分段控件 胶囊容器 + 内嵌胶囊 两个纯文字 双层胶囊只为包住两个字，是纯装饰。字重与颜色足够区分编辑／预览。
eyebrow 小标签 一屏 3 个 0 个 三处都挂小标签等于都不挂。信息由面包屑和标题承担。
属性区 边框 + 底色 + 状态胶囊 一条发丝线 + 键值 三样叠加只为说「这是一组」，一条线就够。状态改成 5px 橙点，不用胶囊。
橙色面积 约 6% 约 1.5% 只剩四处：选中条、引用竖线、勾选框、链接下划线。都是小面积、有语义的位置。
标题尺度 31px 27px 文档不是落地页。27px 已经能压住层级，31px 是在争注意力。
02

浅色

纸白底 · 发丝线分栏

三栏是一条连续纸面上的三个区域，不是三张卡。界线只有一条 1px 线，选中只靠 2px 橙条和一层几乎看不见的底色。

画布 #FAF8F3 纸面 #FDFBF6 发丝线 #E9E2D3 墨 #191610 橙 #F6821F 圆角 6 / 3 投影 0
关键取舍清单的选中行背景几乎不可见（3.5% 墨），真正的信号是左侧那 2px 橙条。这样扫一列标题时不会被色块打断。
风险去掉了卡片，清单条目之间没有线，长列表（20 条以上）可能黏在一起。届时加 1px 极淡行线，而不是把卡片加回来。
03

深色

暖炭底 · 同一套线

深色版不做反相，只把纸与线各压一档。因为已经没有投影，深浅两版的分隔逻辑完全一致——这是最能证明「主题与逻辑解耦」的地方。

画布 #15130F 纸面 #17150F 发丝线 #2E2922 墨 #F2EDE2 橙·文字 #FBAD41 圆角 6 / 3 投影 0
为什么画布与纸面几乎同色#15130F 与 #17150F 只差一档，靠 1px 线分栏。深色下任何底色差都会被放大成色块，宁可极微。
风险低对比线（#2E2922）在部分廉价屏上会消失。备选是把线提到 #3A342B，代价是又变重一点——这一条需要真机确认。
04

保留了什么

参考页的骨，不是皮

减掉的都是「叠加的分隔手段」，参考页真正的识别特征全部还在。

特征在哪不可替代的地方
衬线标题 500品牌名 / 文档标题 / 小标题中文宋体与无衬线正文的对比，是这套语言最不可替换的部分
等宽小标签日期 / 字数 / 属性名 / 面包屑把「元数据」和「内容」在字形上分开，不需要靠颜色或边框
纸面与暖调#FAF8F3 / #191610 / #F6821F整页只有一种底色，靠留白和一条线呼吸
单一强调色4 处小面积橙不再承担「按钮」，只承担「这里是你正在看的位置」
每个地方，只留一种分隔手段。
如果这版还重，下一刀切在字号层级和清单行高上——但先确认方向对不对。
