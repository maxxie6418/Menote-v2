Menote V2 · Direction 05 · 2026-10-31

先让界面变灰，再让橙跳出来

暖黄不是来自某一个颜色，是来自「所有中性色都带黄」：画布、侧栏、浅层、连发丝线都是暖的，橙再叠上去，整屏就是一层滤镜。 更麻烦的是那个参考页本身就是 Claude 的配色（象牙底 #FAF9F5 + 陶土橙 #D97757），我把它和 Cloudflare 橘放在一起，等于三家撞色。

v5 把中性色全部退回真正的灰，让橙成为全屏唯一的暖色；结构上借了 Notion 三条做法——侧栏整块底色配选中块、属性区做成无框的 key-value 表、行内操作只在悬停时出现。同时把上一版压过头的行高与分组放回来。

配色修正

暖色只剩一处

判断标准很简单：把所有橙色遮住，界面应该看起来是灰的，不是米黄的。

侧栏#F4EFE4 米黄#F7F7F5 中性灰（Notion 侧栏同款明度）
浅层 / 选中#F0EADC 暖褐#F4F4F2 / #EDEDEA
发丝线#E5DCC9 暖褐#E7E7E4 中性灰

橙的职责按钮 / 选中 / 标题线 / 勾选 / 链接只做图形标记：选中点、状态点、勾选、装饰短线
链接#B4530F 橙褐，与橙抢角色#0051C3 Cloudflare 文档蓝
衬线品牌 / 标题 / 正文小标题只留品牌与文档标题两处
为什么链接改蓝橙色一旦同时是品牌色和链接色，满屏的"可点"就全是橙，暖感翻倍。Cloudflare 自己的文档就是橙做品牌、蓝做链接。
为什么减衬线象牙底 + 宋体 + 陶土橙是 Claude 的三件套，缺一件就不像了。底和橙已经改掉，小标题再退回无衬线，暖感彻底下来。

03

借了 Notion 什么

四条拿走，两条不要

Notion 的可取之处不是它的长相，是它「用灰阶和留白承担结构」的方法。它的克制正好治我们上一版的暖与挤。

做法用在哪为什么
侧栏整块底色 + 选中块侧栏 #F7F7F5 / 选中 #EDEDEA分区靠一层底色，不靠边框；选中项是"更深的同一色"，不是另一个色系
属性区无框 key-value两列，每行 30px，底部 1px 淡线键值靠列对齐就能读，不需要外框、底色和胶囊三件套
悬停才出现的行内操作清单行右侧 ⋯，仅在悬停/选中时显示默认画面干净，需要时才出现——比常驻图标更高效
正文比 UI 大一号正文 14px / UI 12.5px阅读区与操作区的字号台阶，是"结构感"最省力的来源
没拿的两条一是 Notion 正文 16px——笔记工具列表密度会崩，取 14px；二是它的绝大多数中性色，Notion 整体偏灰、没有性格，我们要留一条宋体标题和一枚橙。
也没拿它的 emoji 图标笔记图标是个人表达，但产品层面用 emoji 当图标会破坏字形秩序；这里用等宽小标签（NOTE · UE5）承担同样的"这页是什么"的作用。
04

浅色

白底 · 灰结构 · 橙标记

挡住橙色之后，画面是冷的——这时候橙才真的跳，而且不再累眼。正文 14px 让阅读区自然浮起来。

主区 #FFFFFF 侧栏 #F7F7F5 选中 #EDEDEA 发丝线 #E7E7E4 墨 #1A1A18 橙 #F6821F 链接 #0051C3 行高 64 正文 14px
橙的四个落点侧栏选中点 4px、状态点 5px、勾选框 13px、标题上方 14×1.5 短线。全屏橙色面积约 1.2%，都是点与条，没有面。
可读性橙在纯白上 2.5:1，所以不承载任何文字；链接蓝 #0051C3 是 6.6:1。正文 #50524F 对白底 8.2:1。
05

深色

冷炭 · 不用暖黑

深色最容易犯的错是沿用暖黑（#14120F），那会让整屏发褐。这里用中性冷炭 #191B1D，橙在冷底上比暖底干净得多。

主区 #191B1D 侧栏 #141618 选中 #2A2E31 发丝线 #2C3033 墨 #E9EBED 橙字 #FBAD41 链接 #7FA8FF 行高 64
链接要提亮#0051C3 在深色上只有 2.5:1，换成 Cloudflare 蓝的亮版本 #7FA8FF（7.4:1）。
主按钮反相深色里墨色实心会沉进背景，改为浅灰实心＋深字——它是全屏最亮的一块，也是唯一一处刻意反相。
灰承担结构，橙只承担位置。
