Menote 默认主题配色 · 四选一

问题根因：新账号默认皮肤 shadcn 的所有颜色都是 oklch(x 0 0)——彩度为 0 的纯灰阶，并且把 --app-accent 直接映射到了黑白 primary。结果是：logo 是暖橙的，界面却连那枚橙都丢了，主按钮黑底白字，整屏黑白。下面四个方案在同一个真实界面上切换对比，点右上角切浅色/深色。

Logo 渐变 #F6821F → #FBAD41 · 深橙 #F15A24 · 浅橙 #FDBA74 现状 --app-accent: var(--primary) = oklch(.205 0 0) 约束：橙色 2.58:1 不做正文，只做标记；按钮字用深棕 #241505
界面配色预览

落地建议（推荐方案 B）

只改 tokens.css 里 [data-skin="shadcn"] 的令牌块，结构与组件尺寸一律不动——和 2026-11-12「只换强调色」的处理方式同源。下面是浅色档的关键改动：

令牌现状（纯灰）方案 B（暖中性 + 橙）作用
--app-accentoklch(.205 0 0) 近黑#f6821f主按钮、选中条、装饰短线、引用线
--app-accent-textoklch(.985 0 0) 白#241505橙底上的字，压深到 6.87:1
--app-accent-fgvar(--foreground)#b4530f（深 #fbad41）浅橙底上的文字 / 选中项文字
--app-accent-subtlevar(--accent) 冷灰#fef2e7（深 #3a2716）标签胶囊、收件箱浅底
--app-linkvar(--foreground) 黑#b4530f（深 #fbad41）可点击文本，对比度 AA 以上
--app-bg-sideoklch(.985 0 0)#f7f5f0侧栏底，带极弱暖意，与橙同源
--app-ring / focusoklch(.708 0 0) 灰rgba(246,130,31,.35)焦点环改橙，与强调色一致
--app-surface（深）#1c1c1f 微冷#232322深色：中性保留极弱暖倾向（R≥B，通道差 1–5）；正文/背景对比约 11:1，去掉近白文字的刺眼感；橙强调不变
--app-bg-side（深）#232326 微冷#2b2b29
--app-fg（深）#f4f0ea 近白#dcdcd7
取舍提醒：方案 B 的中性只是「极弱暖」（侧栏 #f7f5f0、纸面 #fffefc），远没到象牙底，遮住橙后仍近似中性——没有破坏「界面后退、内容在前」。方案 C 的品牌渐变按钮最贴 logo，但暖度与橙色面积明显更大，是最跳跃的一档。三档都 satisfies 对比度红线；需负责人确认采用哪一档后，我再落到 tokens.css 并同步 DESIGN.md，当前不擅自改生产令牌。
