## 2026-10-31：E2 内容闭环实现（Note/Memo 本地日常可用）

- **编辑器选型 [实施定]**：SourceEditorAdapter 采用等宽 textarea（非 CodeMirror）——M2 源码形态是临时形态（FR-EDT-1 定稿 M3 落 WYSIWYG），原生输入法/撤销/选区行为零集成风险、键入路径最短（NFR-10）；`EditorAdapter` 接口按工程设计 3.2 预留 loadMarkdown/getMarkdown/focus/destroy，M3 换 WYSIWYG 仅替换实现。Tab 插两空格，所见即源码。
- **Note 闭环**：新建先写再分类（点新建立即进空白编辑页）；标题/正文自动保存 800ms 防抖静默后台化（Ctrl/⌘+S 立即保存；失败有「保存失败·重试」可见不阻断提示）；编辑/预览两常驻模式（FR-EDT-2），预览 react-markdown+remark-gfm 渲染（md-* tokens）；标签增删；收件箱/草稿箱整理对话框（移入主题/分组、直接删除，FR-IA-9）；移入回收站。主题树真数据：新建主题/分组（一层限制校验）、改名、软删；选中层级清单穿透聚合。
- **Memo 闭环**：侧栏快速输入（单行展开多行、⌘/Ctrl+Enter 保存、Esc 收起保留草稿、保存后留在当前页）；时间线卡片原位编辑（失焦提交）；任务复选框可点击改写正文 `[ ]`/`[x]`（setTaskCheckbox 按文档序定位源行，引用/缩进任务识别）；todo 侧板：todo/doing/done 三组、拖入分组即改状态（HTML5 拖拽）、勾选完成/取消回待办、点文本移出、已完成默认折叠。

## 2026-10-31：E3 属性区与表格结构化编辑实现

- **开放项 #5 定稿（待负责人批次末确认）**：保留命名空间键名 = `props`（属性定义：type/label/options）与 `fields`（表格字段定义）；8 类型 text/multiline/number/date/select/multiselect/checkbox/link，表格侧无 multiline（FR-PROP-4）。定义写入实现于 lib/frontmatter（yaml Document AST）。
- **frontmatter 往返（C-1/FR-PROP-7）**：基于 yaml 包 Document API——未触碰的键（含引号风格与注释）逐字节保留；被编辑的键按 YAML 规范重排（语义不变，仅编辑值自身重序列化）；解析失败按无属性处理不阻断。写回统一走 saveItemContent（rev 推进），写命令经串行队列保证属性区编辑与正文自动保存互不覆盖（FR-PROP-3 统一文档更新链路）。
- **属性区（FR-PROP-1/2/3/6/7/8）**：标题下轻量排版、可折叠、空文档只显示「添加属性」；编辑/预览两态均可编辑；无定义键安全推断（date 固定格式/number 精确往返/link/布尔原生/数组原生，其余文本）；select/multiselect 候选显式定义（FR-PROP-5），值不在候选中标明；属性区多选为 YAML 原生数组（FR-PROP-8）；键可删除。编辑器增加 registerApplyExternal 强制回灌句柄：结构化写回后刷新编辑器并清脏标记，避免属性编辑被正文草稿覆盖。
- **表格（FR-TBL-1/2/5/6/7）**：lib/gfmTable 解析（含转义竖线/多行块）/渲染/替换；写回契约=多选 `A, B`、单元格禁换行、竖线转义、首尾空格不保留；文档工具条「表格结构化编辑」对话框：网格逐格编辑（表头文本、字段类型按 fields: 定义分派 7 类控件）、加行/删行、多表格切换；无定义字段按文本可编辑（FR-TBL-4/5）；「抽出为独立表格文档」生成 fields:+表格主体的新笔记（FR-TBL-3）。
- **验证**：`pnpm typecheck` 全过；测试 68 项（shared 3 / web 29 / worker 36）全过——新增 frontmatter 往返/保留键/降级推断 3 项 + GFM 表格解析转义契约 1 项；`pnpm build` 通过；结构检查（样式零字面量——对话框居中/宽度 3 处转 token）全过。版本 0.0.4 → 0.0.5。
- **边界与遗留**：①表格损坏降级（table→note 单向）与封存钩子留待 G8（本节点不做损坏检测降级，不可解析块不进结构化编辑）；②表格多选候选禁逗号校验在字段定义 UI 暂以逗号分串处理，逐字符强校验随 G8 回归补强；③属性区与表格的键盘走查/视觉待负责人浏览器复核；④M3 打磨输入：属性区行内编辑的焦点流转、表格列宽自适应。
