## E2 Note/Memo 本地内容闭环（核心临时编辑）

- **状态**：✅ 实现完成（2026-10-31，详见开发记录；检索后置 E5、附件 G5、同步 G6）
- **需求与输入**：FR-IA-1～9、FR-EDT-1/2（源码形态）、FR-MEMO-1～5、FR-VER-7、NFR-10。
- **依赖**：E1。

### 编辑器宿主与源码适配器

1. `EditorHost` + `EditorAdapter`（loadMarkdown / getMarkdown / onSelectionChange / onScroll / destroy）；`SourceEditorAdapter` 选型 [实施定]：CodeMirror 6 或等宽 textarea+高亮，开工时定并记录理由。Milkdown 为 M3 `WysiwygAdapter` 底座（负责人 2026-10-31 确认接入，最终以往返 PoC 复核保留更换可能）；M2 不引入 Milkdown。
2. 编辑/预览两个常驻模式（FR-EDT-2），预览正文只读；渲染走既有 `md-*` tokens。
3. 自动保存静默后台化（NFR-10）：输入不阻塞、保存不打断；保存失败有可见但不阻断的提示与重试。
4. 新建笔记先写再分类（FR-IA-6）：点新建立即进入空白编辑页，不弹必填归属表单。
5. 空白草稿不落库（FR-VER-7）：三道闸（非 create 状态不动 / 队列有行不动 / 仍空白才回收）+ 启动兜底扫描带宽限期。

### 编辑器独立性硬规则（负责人要求：尽量保持独立、不排除更换）

- `@milkdown/*` 只准出现在 `features/editor/` 内部；其类型不进入 services/shared；adapter 进出仅 markdown 字符串与纯数据；不引入 Y.js 协作；不使用 Crepe 成品壳（用 core/kit 自组插件，自研浮条/表格控件放 adapter 外层，随编辑器更换可带走）。
- 四候选对比结论（2026-10-31，详见[体验线开发记录](20261031-M2-开发记录-体验线.md)）：Milkdown（主测）/ MDXEditor（同场）/ Tiptap（第三样本）/ ProseMirror 原生（兜底）；无一开箱满足 FR-EDT-5，往返安全须 PoC 语料逐字节验证，必要时采用「未知块占位保护」策略。

### Note 本地闭环

1. 主题/分组树管理：建/改名/软删，分组最多一层（FR-IA-1）；目录树只显示主题与分组（FR-IA-3）。
2. 选中层级清单**穿透聚合**（直属+子层级，扁平排列），列表/网格双布局接真数据（FR-IA-3/7）。
3. 收件箱/草稿箱（FR-IA-2/9）：自建未归类进草稿箱；整理出箱（指定主题/分组后自动移出、支持直接删除）；不做 Note→Memo 转换。
4. 标签写入与展示（FR-IA-8）。

### Memo 本地闭环

1. 时间线默认视图；快速输入（FR-IA-5）：默认单行、点击展开多行、占共享区域不推移导航、保存后留在当前页、收起保留未完成草稿。
2. 原位编辑（FR-MEMO-1/4）：编辑态为源文本（等宽所见即源码），保存/失焦渲染；不打开完整 Note 编辑器；无常驻格式工具栏。
3. 轻量语法集与降级（FR-MEMO-2）：不支持的标题/表格/脚注原样存储、降级显示。
4. 任务列表复选框可点击改写正文 `[ ]`/`[x]`（FR-MEMO-3）；todo 侧板（FR-MEMO-5）：单一互斥状态、拖入分组即改状态、已完成组默认折叠、不遮挡时间线、不延伸到 Note 阅读区。

### 本地多标签刷新

BroadcastChannel 广播（不带内容）触发本地重读；为管理线 G6 outbox/Web Locks 主锁预留接点。

**E2 出口**：

- 断网与刷新场景：本地新建/编辑正常，刷新不丢数据；空白草稿三道闸测试通过。
- 键入与保存互不阻塞，滚动流畅；体验基线记录在案。
- FR-IA-1～9 本地行为按需求说明书 2.2/2.3 交互走查；结构检查与冒烟通过。
- **边界**：无云端同步、无附件上传、无加密与版本历史；同步状态脚注不还原；搜索入口不做（见 E5）。

## E3 属性区与表格

- **状态**：未开始
- **需求与输入**：FR-PROP-1～8、FR-TBL-1～8、C-1；开放项 #5。
- **依赖**：E2；表格降级封存钩子对接管理线 G8 版本封存接口（G8 实现后生效，先留钩子）。

1. YAML 保留命名空间键名、8 类型集合与序列化规则定稿（与表格字段共用定义；表格侧不提供多行文本）——关闭开放项 #5。
2. 属性区轻量排版（YAML 默认不显示为源码块）、点击值直接编辑、可折叠、空文档不铺空字段（FR-PROP-1/2）；预览态属性区仍可独立编辑，写回经统一文档更新链路（FR-PROP-3）。
3. 无定义键安全推断（能无损解析才启用对应控件，否则文本，FR-PROP-6）；外来键与未知值原样保留、降级文本、原样写回（FR-PROP-7）；属性区多选为原生数组（FR-PROP-8）。
4. 表格：GFM 解析↔结构化编辑（`TableBlock`）；无定义表格必须可编辑（FR-TBL-5）；字段定义存表格主体文档 YAML `fields:`，「以表格为主体」的 Note 作为绑定目标（FR-TBL-2/3）；写回契约（多选 `值A, 值B`、候选禁逗号、单元格禁换行、竖线转义，FR-TBL-6）；类型控件 7 种（FR-TBL-7）。
5. 表格结构损坏降级（table→note 单向）前调用版本封存接口（FR-VER-2 触发点）。

**E3 出口**：属性区与表格用含未知语法样本验证往返不丢内容（C-1/NFR-3）；结构检查通过。
