# TP2 多维表格体验优化

- **创建日期**：2026-11-04
- **所属任务包**：[TP2 · 多维表格](20261101-TP2-多维表格.md)
- **状态**：代码已实现；Web typecheck/build 通过；真实浏览器与移动端走查待做
- **需求基线**：FR-TBL-1～18；整页表格文档 `type: "table"`，标准 GFM 表格 + YAML `fields:`

## 1. 目标

让多维表格在连续录入、键盘操作、批量整理、查看长数据和移动端使用时更顺手，同时继续以本地内容和标准 GFM 表格为基础。需求说明书 v1.40 登记 FR-TBL-12～17，v1.45 增加 FR-TBL-18。

## 2. 优化范围

### 2.1 键盘连续编辑

- 单元格间以 Tab / Shift+Tab 前后移动；末尾单元格按 Tab 新增数据行并聚焦新行首格。
- Enter 开始或提交当前编辑，Esc 放弃本次未提交输入并还原原值。
- 行列增删、编辑提交和焦点去向保持一致，避免键盘操作后焦点丢失。
- 先盘点当前实现，保留已符合预期的行为；补齐缺口时统一桌面键盘与可访问性语义。

### 2.2 剪贴板批量粘贴

- 接受制表符分隔的多行、多列纯文本（包括从 Excel / Google Sheets 复制的区域），按当前焦点单元格开始填入。
- 表格空间不足时按粘贴区域扩充数据行；列数超出既有字段时不得静默丢弃，给出可恢复的提示并提供新增列选择。
- 按目标字段类型复用已有解析与校验；遇到无效值时明确标出单元格与原因，支持撤销整次粘贴。
- 竖线、换行和多选分隔符最终仍须遵守 FR-TBL-6 的 Markdown 写回契约。

### 2.3 多行选择与批量操作

- 提供行选择控件及连续区间选择；清楚显示已选行数。
- 首批操作：批量删除、复制所选行、拖动所选行重排；删除与粘贴/重排均支持撤销。
- 删除前说明影响行数；不把行号当稳定身份，重排后重新编号并按标准 GFM 顺序写回。
- 与 FR-TBL-10 单行拖动共存，不改变连接器可见行 ID 的值或对应记录。

### 2.4 排序与筛选

- 列菜单可按文本、数字、日期及单选字段排序；排序结果只改变当前表格文档的行顺序并写回 GFM。
- 支持按字段值筛选：文本包含（不区分大小写）、数字/日期等于或大于/小于、单选/多选候选匹配、复选框状态。
- 明确区分「当前视图隐藏行」与「删除数据」；筛选条件清除后所有记录重新可见。
- 排序空值置末尾；多选值按字段候选顺序比较，剩余值按文本比较。排序作用于全部行。
- 筛选仅当前页面会话有效，不改正文；排序改变行顺序并写回 GFM。

### 2.5 列宽与长内容

- 桌面端支持拖动列边界调整宽度，并保持表头与全部数据单元格对齐。
- 长文本单元格提供完整查看与编辑入口，不要求用户猜测被截断内容。
- 窄屏下保留可理解的横向滚动与当前列定位，不压缩到不可读；行号、拖动手柄和行操作仍可触达。
- 列宽按账号与条目分别保存在本机偏好，不写入 Markdown 或同步；同设备刷新/重开保留，其他设备显示默认宽度。

### 2.6 新增行与字段的连续录入

- 新增行后焦点进入新行首个可编辑单元格；批量粘贴扩行也遵循相同焦点规则。
- 添加字段后焦点进入字段名输入；确认后可继续配置类型和候选值，取消时不留下空字段。
- 连续添加行、字段时减少重复打开/关闭菜单的操作，同时保留清晰的取消与保存反馈。

### 2.7 移动端操作

- 检查横向滚动、表头辨识、行号与行操作在窄屏下的可达性。
- 行重排使用明确的拖动手柄与触控反馈；不能只依赖桌面原生拖放。
- 输入控件、菜单项与行操作满足现有移动端触控目标规范，并避免编辑时页面意外横向跳动。

### 2.8 字段列拖动重排（FR-TBL-18）

- 在每个字段表头提供拖动手柄，可将列移动到其他列之前或之后；触屏设备使用指针拖动。
- 列重排同时更新 `fields:` 定义顺序、GFM 表头和每行单元格顺序，任何值都必须继续对应原字段。
- 写回沿用当前 Markdown 自动保存与同步链路；空白脚手架也按新字段顺序显示。

## 3. 约束与依赖

- 内容仍以本地库为源；写入通过现有服务层与自动保存链路完成，不由 UI 直接访问 IndexedDB。
- 单元格值继续遵循 FR-TBL-6，字段类型继续遵循 FR-PROP-4 / FR-TBL-7，行顺序继续遵循 FR-TBL-10。
- 已登记范围包括需求说明书 v1.40 的 FR-TBL-12～17 与 v1.45 的 FR-TBL-18。键盘、剪贴板、多行操作、排序筛选、列宽持久化和列重排按对应 FR 验收。
- 类型校验失败不得静默丢值；批量变更应能整体撤销，或在无法整体撤销时明确呈现部分成功结果。
- 样式使用 `tokens.css`；新建模块前先评估现有 `features/table/`，避免拆成零散文件。

## 4. 建议交付顺序

1. 真实浏览器走查并盘点键盘操作、添加行/字段焦点与长内容现状。
2. 键盘连续编辑与新增行/字段焦点收口。
3. 剪贴板多格粘贴与整次撤销。
4. 列宽、长内容和移动端可用性。
5. 多行选择及批量操作。
6. 排序与筛选（按 FR-TBL-15/16 实施）。

此顺序可在体验设计阶段调整；新需求的优先级与验收标准需随 FR 一并确认。
