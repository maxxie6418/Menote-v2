## 1. 目标

补齐设计中的「多维表格」文档形态：用户创建空白文档后可选择将其转为多维表格（`Item.type: "table"`，契约已预留），获得类飞书多维表格的整页网格编辑体验；内容载体仍为标准 GFM 表格 + YAML `fields:`（C-1），不制造第三种内容形态（C-2）。

## 2. 范围

**做**
- 空白草稿形态选择入口（`BlankFormChooser`）与 `setItemForm` 转换服务（note↔table，仅空白期可切）。
- `TableDocument` 整页网格编辑器：字段（列）管理、行管理、类型化单元格编辑。
- 单元格控件共享化：从 `TableBlockDialog` 抽出 `TableCellEditor` 并升级（双轨 FR-TBL-2）。
- 结构损坏降级 table→note 单向，降级前自动封存版本（FR-VER-2）。
- 「抽出为表格文档」产物对齐为 `type:"table"`。

**不做**（本次）
- 视图级排序/筛选/搜索/统计（FR 未覆盖，留后续迭代）。
- 表格文档源码直改形态（仅网格；损坏走降级）。
- 公式、自动化、跨表关系、数据库式工作流（FR-TBL-8）、第二套存储（C-2）。
- Worker/shared 契约改动（`type:"table"` 已全链路预留，验证即可）。

## 3. 接口设计

### 数据模型（零新契约）
- 表格文档 = `Item.type: "table"`（`src/shared/src/types/item.ts` 已预留，与 note 同构可加密）；D1 CHECK、Worker `db/sync.ts` 映射均已允许。
- 内容 = YAML frontmatter（`fields:` 字段定义，沿用 `lib/frontmatter.ts`）+ 正文单个 GFM 表格（`lib/gfmTable.ts` 解析/写回）。
- 加密（单篇/私人空间）、outbox 同步、冲突副本、版本封存、备份导出按 Item 泛化自动继承。

### 服务层（`src/web/src/services/contentService.ts`）
| 函数 | 语义 | 守卫 |
| --- | --- | --- |
| `createNote(userId, { type? })` | 创建 note/table 文档，默认 note | — |
| `setItemForm(userId, id, to)` | 空白期 note↔table 互转（**锁定闸口唯一实现点**），metaRev+1 走 outbox | `isBlankDraft(item)` 且 plain scope |
| `degradeTableToNote(userId, id)` | 结构损坏降级（单向），降级前 `archiveVersionBeforeSave(..., "manual")` 封存（FR-VER-2） | `type==="table"` |

### UI 分支
- `NoteDocument`：`isBlankDraft && type==="note"` 渲染 `BlankFormChooser`（非打断式选择条）；`type==="table"` 编辑模式渲染 `TableDocument`（预览仍 MarkdownView）。
- `EncryptedNoteView` 解锁态同样按 type 分支（加密表格文档解锁后进网格）。

## 4. 多维表格功能清单

| # | 功能 | 依据 |
| --- | --- | --- |
| 1 | 字段系统：7 种类型（文本/数字/日期/单选/多选/复选框/链接），定义持久化 YAML `fields:`，与属性区共用同一套定义与序列化 | FR-PROP-4 |
| 2 | 类多维表格单元格编辑控件 | FR-TBL-7 |
| 3 | 列管理：加列（命名+选类型）、重命名（`renameDef`）、改类型、删列；单选/多选候选值管理（禁逗号） | FR-TBL-3/6 |
| 4 | 行管理：加行、删行 | FR-TBL-2 |
| 5 | 无字段定义的列按文本编辑、所见即写回 | FR-TBL-4/5 |
| 6 | 写回契约：多选 `值A, 值B`、单元格禁换行、竖线转义 | FR-TBL-6 |
| 7 | 载体永远是标准 GFM 表格，脱离 Menote 可直读、可导出 | FR-TBL-1、C-1 |
| 8 | Note 内表格弹窗与表格文档共享同一套单元格控件（双轨） | FR-TBL-2 |
| 9 | 结构损坏降级 table→note 单向，降级前自动封存版本 | FR-VER-2 |
| 10 | 自动继承 Note 全部链路：主题分组/标签/置顶、单篇加密+私人空间、版本历史、同步冲突副本、备份、导出 | C-7、FR-SYNC/BAK |
| 11 | 明确不做：公式、自动化、跨表关系、数据库式工作流 | FR-TBL-8 |
| 12 | 体验打磨：添加字段改为入口旁浮层；统一表头/单元格列宽；数据行可拖动排序，改序写回 GFM 并随现有自动保存链路保存 | FR-TBL-10（新增） |

**实现约定**（2026-11-01）：改列类型不迁移既有值（类型是增强信息，FR-TBL-4 精神）；checkbox 单元格对历史非布尔值保留显示、勾选即覆盖为 true/false；改类型/删列均不弹批量改值确认（仅删列确认）。
