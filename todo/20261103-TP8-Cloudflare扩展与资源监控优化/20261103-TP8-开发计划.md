- 延伸候选（Durable Objects、Browser Rendering、Cache API、Turnstile）——负责人确认立项后才进本包。

## 4. 验收标准

- 规划内启用的每个服务：免费档内可用、不新增必填部署密钥、绑定随部署自动预配（13.1/12 章承诺不变）。
- 监控三类口径（官方/估算/本地）不混淆；增强模式面板打开不再每次实时外呼；快照时点与滞后声明可见；监控自身 D1 写入与外部查询负担不高于现状（13.7）。
- 加密正文不入 FTS5 索引、不提交云端 AI（安全红线）；AI 结果存储边界按开放项 #1 定稿执行。
- 工程纪律：新模块登记工程结构设计；SQL 只在 db 层；单文件 ≤ 1000 行；样式零硬编码。
