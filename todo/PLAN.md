# Menote V2 总计划（任务执行）

- **定位**：`todo/` 是任务执行文件夹，本文件为里程碑与工作项的状态总表；每个里程碑集中使用一份开发计划和一份开发记录（必要时最多三份文档）。开发顺序、依赖与验收详见 [开发计划](开发计划.md)。
- **查阅优先级**：开发时先查对应里程碑的开发计划与开发记录，缺失再查 `wiki/` 兜底（需求说明书 → 工程结构设计 → 主文档）。
- **记录义务**：开发中及时更新里程碑开发记录 与本文件状态表；里程碑推进涉及定稿时同步主文档与需求说明书。
- **文档过时/冲突**：先提醒产品负责人确认，再修复；不得擅自修改定稿结论。
- **状态图例**：⬜ 未开始 ｜ 🔵 进行中 ｜ ✅ 已完成 ｜ ⛔ 阻塞

项目当前版本：**0.0.0**；升级及并行后缀规则见 [AGENTS.md](../AGENTS.md)。

## M2 工作规划（M1 完成后细化）

预定范围：认证会话与多用户隔离、结构化存储与同步、内容管理闭环（编辑器为 md 源码形态）、加密（私人空间+单篇+恢复码）、版本历史与回收站基础、调度框架与备份基础、可选剪藏插件启动。正式数据进场在 M2 末，前置条件为从远端取回并在干净环境完成含附件、加密内容及恢复码的恢复实测。同步与附件清理细节在核心内容完成后在里程碑计划内细化；影响数据正确性的规则须在对应实现及正式数据进场前确定。加密密钥封装与备份快照一致性在对应实现前专项设计。

## M3 / M4 工作规划

M3：WYSIWYG 落地、交互与性能打磨、恢复体验及异常场景完善。M4：MCP、AI、FTS5、样式编辑 UI、监控增强、发布候选验收。均待前置里程碑收尾时细化。
