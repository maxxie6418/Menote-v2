## 2026-11-16：Memo 标签展示与侧栏导航

- **来源与确认**：负责人要求 Memo 中的标签文字使用不同颜色或样式，与普通 Memo 正文区分。
- **来源与需求**：负责人要求 Memo 正文标签用颜色/样式区别于普通文字，并补充报告全局侧栏标签点选后无法跳转至对应 Memo。按 FR-IA-8 / FR-MEMO-9 实现。
- **展示实现**：shared `findMemoTagRanges` 复用既有标签识别规则并提供文本范围；`MarkdownView` 增加可选 `highlightMemoTags` rehype 渲染，仅 Memo 正文、引述快照和移动端随记启用；样式使用既有强调色、圆角和间距令牌，不改写内容或索引。
- **导航根因**：全局 `useAllTags` 包含 Memo 标签，但侧栏点击进入 Note 标签路由，而 `useTagItems` 明确排除了 Memo，因此时间线中没有对应记录。
- **导航实现**：新增 `useMemoTags` 汇总普通 Memo 可见标签；全局侧栏、书脊导航和移动端主题/标签入口在标签匹配 Memo 时进入 `/memos/tag/<tag>`，Memo 页面筛选匹配记录并定位首条；仅有 Note 的标签仍保持原路由。
- **文档 / 版本**：需求说明书更新至 v1.62（FR-IA-8、FR-MEMO-9）；DESIGN.md 更新至 v1.12；工程结构设计更新至 v0.19；根项目版本 `0.3.2` → `0.3.3`。
- **验证**：`pnpm typecheck` 与 `pnpm build`（含 Worker dry-run）通过。Vite 有动态导入与主包体积告警，但构建成功。未运行测试套件或应用内走查。
- **状态**：实现、文档、类型检查与生产构建完成；待负责人应用内体验确认。
