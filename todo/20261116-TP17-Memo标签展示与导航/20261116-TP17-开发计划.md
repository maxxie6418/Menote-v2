# TP17 开发计划：Memo 标签展示与导航

日期：2026-11-16 ｜ 状态：实现完成；类型检查与构建通过，应用内走查待确认 ｜ 关联：M3 / Memo 体验

## 1. 目标

让 Memo 正文中的 `#标签` 在阅读时与普通文字更易区分，并修复全局侧栏标签不能定位到对应 Memo 的问题；保留标签位于正文里的既有口径。

## 2. 需求依据与范围

- **FR-IA-8**：点击有普通 Memo 记录的全局标签后直接进入对应标签的 Memo 时间线；Note-only 标签维持原有笔记列表行为。
- **FR-MEMO-9**：标签仍以正文文本为唯一载体，展示态可对标签应用行内强调样式；不新增独立标签行或改变存储。

### 范围内

- 用 shared 标签解析位置为正文中有效 `#标签` 包裹轻量强调样式。
- 桌面与移动端 Memo 时间线、Memo 引述快照和引述预览启用该样式。
- 全局侧栏、书脊栏和移动端主题与标签导航检测 Memo 标签；命中时进入按标签过滤的 Memo 时间线并定位到首条匹配项。
- 没有 Memo 使用的标签仍进入原有笔记标签列表。
- 使用现有强调色和间距令牌，确保标签文字仍清晰可读。
- 更新需求、产品主文档、DESIGN.md、工程结构设计与 TP17 记录。

### 范围外

- 不改写 Markdown 源文、标签索引或筛选/导入行为。
- Note 正文不启用 Memo 标签样式。
- 不恢复卡片底部或正文之外的独立标签行。

## 3. 实现与验收

- 正文中的标签（包括 `#`）呈现轻量强调色行内胶囊，与普通文字有清楚但克制的区别。
- 点击全局 Memo 标签后，桌面与移动端均进入该标签的 Memo 时间线，列表筛选正确且视图定位到首条匹配 Memo。
- 仅有 Note 记录的同名标签继续打开原有笔记标签页。
- 保存、编辑、复制和筛选仍使用原始 `#标签` 文本与既有 shared 规则。
- 普通文字、Markdown 标题、URL 锚点及无标签 Note 的呈现不变。
- 主题样式由设计令牌驱动，不在组件内硬编码颜色或间距。
