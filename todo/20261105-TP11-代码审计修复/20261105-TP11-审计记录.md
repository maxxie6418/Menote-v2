## 2. 必须修的实现缺陷

1. **全量重同步只返回最早 200 条，客户端先删本地。** `buildSyncPage` 缺口时 `readAllItemsPage(..., 0, 200)`，`nextCursor` 写成 `oldestSeq - 1`，第二次请求不再翻页。超过 200 条且日志已被裁剪时，本地永久缺条目。
2. **备份 BLOB 经 JSON 后不再是字节。** 密钥包装、条目 `content_ciphertext`、设置密文都会坏。恢复 `toB64` 把对象变成 `"[object Object]"`。`topic_key_wraps` 进了包，恢复不读。导入 `slice(0, 5000)` 不报告截断。
3. **分组跨主题移动不落库。** `upsertTopicRow` 冲突时不更新 `parent_id` / `depth` / `is_enc_space`。界面已有 `moveGroupToTopic`（FR-IA-14）。
4. **解密失败写成空密文。** `readPlain` 失败用 `?? ""`，800ms 后自动保存。解除加密在明文未读完时确认也会清空。启用/解除加密不走 `enqueueWrite`。
5. **加密笔记附件明文上传。** 违反 FR-ENC-5 与密文边界。本包不新造附件密钥协议：加密笔记拒绝上传附件（fail-closed）。已在库里的明文对象不回写、不假装已加密。
6. **同步失败一律死信。** 存储故障也被收成 `rejected` 且客户端打上 `Number.MAX_SAFE_INTEGER`。条目写、包装、日志、幂等、引用对齐不是一次 `db.batch`。
7. **15 分钟锁定不看用户活动。** `touchActivity()` 无调用方。锁定时防抖窗口内的加密正文不先落盘。
8. **登出不清本地库，`syncCursor` 全局单键。** 同浏览器换账号会沿用上一账号游标和本地行。
9. **会话 id 存 cookie 原值。** 按安全红线改为只存 SHA-256，旧行首次访问迁移，不强制全体掉线。
10. **变更请求缺 Origin 且带会话 cookie 时不阻断。**
11. **永久删除网络失败被吞掉**，本地已硬删。改为服务端成功后再删本地。
12. **`toB64` 展开运算符**，超长正文可能 `RangeError`。
13. **空白草稿仍入队上传**，与 FR-VER-7「种子从不上传」不符。标题已改的空正文仍上传。
14. **`parseLastOk` 死代码。**
