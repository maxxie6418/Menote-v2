# TP15 开发计划：Flomo 导入与随记标签正文化

日期：2026-11-16 ｜ 状态：已完成 ｜ 前置：M2 管理线导入入口占位（0.2.94）

## 1. 目标

把账户菜单里的 Flomo 导入占位接成可用功能：解析 Flomo 官方导出 zip，落成随记（保留原始时间、正文保留 `#标签` 原文、图片走附件）；同时按负责人要求把随记标签改为「写在正文里」——不再单独渲染标签行，标签入口改为写正文。

## 2. 范围与非目标

**范围内**：

- 解析：`lib/flomoParse.ts` 纯函数（zip → 笔记 HTML → Markdown + 图片清单 + 标签）。
- 落库：`services/flomoImportService.ts`（图片上传、批量写 outbox、按「创建时间 + 正文哈希」去重）。
- 界面：`features/import/FlomoImportPanel.tsx`（选包 → 摘要与预览 → 确认导入 → 进度与结果），接入账户菜单导入窗口。
- 标签正文化：shared 的标签口径（`memoTags.ts`）、随记正文与标签同步、输入框与引述面板的标签入口、Worker MCP `create_memo` 写标签到正文。

**范围外**：Obsidian / Notion 导入（仍显示「即将开放」）；语音等非图片附件类型（跳过）；导入内容的标题与主题归属（随记没有标题也没有主题）。

## 3. 关键设计决策（负责人 2026-11-16 确认）

1. **完全落成随记**：一条 Flomo memo 对应一条 Menote 随记，不转成 Note。
2. **保留原始创建时间**：时间线按 Flomo 原时间排列。
3. **正文保留 `#标签` 原文**：标签既进结构化索引（筛选/分布/图册），也在正文里看得见。
4. **标签正文化**：`tags` 字段退化为从正文解析出的索引；卡片不再渲染标签行；正文任意位置的 `#标签` 都算标签；存量条目的标签在正文末尾补齐后展示，编辑保存一次即落库。
5. **统一来源标签 `#flomo`**：导入条目统一带上，便于筛选与清理。
6. **图片导入、语音跳过**：`file/` 下的 jpg/png/jpeg/gif/webp 走既有附件服务（受策略与 20 MiB 硬上限约束），其余类型丢弃且不留断链引用。
7. **先预览再落库**：批量导入给出条数、时间范围、标签数、图片数与前几条预览，确认后才写。

## 4. Flomo 导出包结构（真实导出核对）

```
flomo@<用户>-<日期>/
├── <用户名>的笔记.html
└── file/<日期>/<用户ID>/<hash>.jpg
```

HTML 里每条 memo：

```html
<div class="memo" data-tags="[&quot;工作&quot;]">
  <div class="time">2025-08-26 22:44:23</div>
  <div class="content"><p>正文……#工作 </p></div>   <!-- 纯图片条目为空或字面量 null -->
  <div class="files"><img src="file/2022-10-05/6645/xxx.jpg" alt="memo image" /></div>
</div>
```

要点：结构化标签在 `data-tags`，正文里同时留着 `#标签` 原文；图片路径多一层用户 ID 目录。

## 6. 验收与边界

- 真实导出包（197 条 / 14 图 / 6 标签）解析结果逐项核对：条数与 Flomo 导出头一致、标签集合与导出页筛选下拉一致、图片零缺失。
- 重复导入同一包：第二次全部跳过，不产生重复条目。
- 单条失败不中断整批，结果给出成功/跳过/失败计数。
- 解析与写入全在本机：压缩包内容不上传、不入库；工作区里的导出包目录被 git 忽略。
- 标签正文化回归：随记新建、编辑、任务复选框、引述、MCP 建 Memo 五条路径的标签行为一致。
