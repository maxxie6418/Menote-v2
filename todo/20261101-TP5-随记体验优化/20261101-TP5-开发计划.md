## 4. 实现约束

- UI 不直连 IndexedDB。统计、热力图、筛选用现有 `useMemos` 与 services，不在组件里开新的数据通道。
- 样式值走 `tokens.css` 的 `app-*`。Memo 正文不复用 Note 的 14px / 1.78，避免两套阅读密度互相覆盖。
- 单文件接近 1000 行就按职责拆。工作栏、顶栏不写进 `MemoTimeline.tsx`。
- 浮层（工作栏、Todo）不进栅格列。折叠或隐藏时时间线宽度变化只来自内边距，不来自列宽重排。
- 加密 Memo 继续不显示明文。热力图和计数可以计入条数，不得展示其正文、标签或附件。
- 日期与标签筛选是视图状态，不写入条目。

## 5. 一期验收

浏览器走查一批含列表、任务、引用、代码块、图片、标签和状态的 Memo：

1. 时间线按今天 / 昨天分组，卡片、轴线、节点与 design.html 第 03 屏一致；悬停只改边框。
2. 点编辑进入源文本，失焦或 `⌘/Ctrl+Enter` 保存后按第 05、06 屏渲染；Esc 放弃本次修改。
3. 勾选任务改写正文 `[ ]` / `[x]`，不改变侧板里的 `status`。
4. 「← 笔记」回到进入前那一篇，树上的选中和清单滚动位置不变。
5. 工作栏四块可用：概述数字正确，热力图反映近 12 周，日期和标签筛选能缩小时间线并清除。
6. Todo 是浮层：拖入分组改状态，勾选完成，取消回到待办，已完成默认折叠；收起后时间线不被一条空列占住。
7. 侧栏是 `笔记 \| Memo` 分段，不再有「Memo 时间线」导航行。`⌘1` / `⌘2` 与分段等价。
8. 加密 Memo 不出现明文。
9. `pnpm typecheck` 与 `pnpm build` 通过。测试如果本轮按负责人要求跳过，在开发记录里写明。
