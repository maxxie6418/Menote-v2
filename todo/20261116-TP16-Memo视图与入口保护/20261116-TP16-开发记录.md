## 2026-11-16：Memo 视图与入口保护（进行中）

- **来源与确认**：负责人要求精简 Memo 侧栏、时间线图片可放大，并在设置增加 Memo 口令选项。负责人补充确认「不需要加密，只是阻拦前端层面的 Memo 入口，内容不需要加密」。因此本功能命名为「Memo 入口口令保护」，不是内容加密。
- **需求冲突处理**：现有 FR-ENC-1 将 Memo 排除在加密作用域之外；该边界保持不变。FR-MEMO-11 只定义前端 Memo 页面入口门禁，明确 Memo 正文/附件仍明文存储与同步，其他展示与 API 可见范围不变。
- **侧记栏**：移除「视图」标题、「连续记录」与「标签分布」区块；保留时间轴/图册、标签筛选及其他统计。墨台皮肤删除相应样式，并更新剩余模块顺序。
- **图片预览**：`MarkdownView` 增加可选 `onImageClick`，只在 Memo 时间线和移动端 Memo 行中启用；正文及引述快照图片可鼠标/键盘打开共享预览组件。复用已鉴权附件 URL，按原比例显示；Escape、点遮罩关闭并恢复焦点。图册原有「点图回 Memo」不变。
- **入口门禁**：设置项进入既有账号同步的 `appearance` 偏好，旧账号默认为关闭。`MemoAccessGate` 包住桌面与移动端 Memo 页面，每次进入重新要求私人空间密码。`privateSpaceService.verifyPrivateSpacePassword` 只解开并清零临时主题密钥，不设置 keyring 状态；不会解锁私人空间或写入密码/密钥。未设置私人空间密码时设置控件不可开启。
- **安全与范围**：这是 UI 层入口门禁，不阻止首页摘要、搜索或 API/MCP 读取；也不改变 Memo 数据模型、服务端可见性或加密边界。设置与验证提示均明示内容仍明文。
- **文档**：新增 FR-MEMO-10/11；同步产品主文档、DESIGN.md、工程结构设计；新增 TP16 计划。M0 总表、版本和最终验收结论待完成后追加。
