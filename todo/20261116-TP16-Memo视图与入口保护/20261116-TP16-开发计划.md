# TP16 开发计划：Memo 视图与入口保护

日期：2026-11-16 ｜ 状态：实现完成；类型检查与构建通过，应用内走查待执行 ｜ 关联：M3 / Memo 体验

## 1. 目标

按负责人 2026-11-16 指示精简 Memo 侧记栏、支持时间线图片放大预览，并增加仅拦截前端 Memo 页面入口的私人空间密码门禁。

## 2. 需求依据与范围

- **FR-MEMO-10**：侧记栏移除「视图」标题、「连续记录」与「标签分布」；保留时间轴/图册切换和标签筛选。桌面与移动端时间线正文、引述快照图片可放大预览。
- **FR-MEMO-11**：可选设置 Memo 入口口令保护，每次进入 Memo 页面验证私人空间密码；只挡页面入口，Memo 内容仍明文存储和同步。

### 范围内

- 侧记栏只移除指定标题与两项统计模块，不移除标签筛选。
- `MarkdownView` 提供可选图片预览回调；Memo 时间线及移动端记录行使用应用内原比例预览，Escape/点遮罩关闭。
- 设置·恢复码增加「Memo 入口口令保护」，作为账号级外观偏好同步；开关开启后每次进入桌面或移动端 Memo 页时验证私人空间密码。
- 验证通过临时解开密码包装并清零结果密钥，不调用私人空间解锁，不记录密码或密钥。
- 同步更新需求、主文档、视觉规范、工程结构与 TP16 计划/记录。

### 范围外

- Memo 正文/附件真实加密、加入私人空间或任何 Worker/同步/MCP 权限变化。
- 对首页摘要、搜索结果等 Memo 页面之外的现有展示增加门禁。
- 图册点击行为变更；图册仍回到原 Memo。

## 3. 关键决策（负责人 2026-11-16 确认）

1. Memo 内容不需要加密；功能名称为「Memo 入口口令保护」，界面明确说明正文与附件保持明文。
2. 使用已有私人空间密码作为校验凭据，不存密码、不解锁空间密钥；未配置密码时禁止启用。
3. 每次重新进入 Memo 页面都重新验证；离开页面即结束本次通过状态。
4. 图片预览复用原附件鉴权 URL，不创建缩略图或本地副本。

## 4. 实现顺序

| 序 | 工作项 | 交付 |
| --- | --- | --- |
| P0 | 精简 Memo 侧记栏 | 标题/连续记录/标签分布移除，标签筛选保留 |
| P1 | 时间线图片预览 | Markdown 图片可点击/键盘打开、关闭与焦点返回 |
| P2 | 私人空间密码校验与页面门禁 | 只验证包装、不解锁或缓存密钥；桌面与移动端共用 |
| P3 | 设置与账号同步 | 设置页开关、旧账号默认关闭、同步到其他设备 |
| P4 | 文档联动、版本与验收 | FR-MEMO-10/11、DESIGN.md、工程结构、TP 记录 |

## 5. 验收要点

- Memo 侧记栏能看到时间轴/图册按钮，无「视图」「连续记录」「标签分布」；标签过滤仍可用。
- 时间线正文与引述快照中的图片可鼠标点击或键盘激活放大；Escape 与遮罩均可关闭并恢复触发焦点；图册仍点图回 Memo。
- 开关关闭时直接进入 Memo；开启后桌面和移动端每次进入均要求私人空间密码；错误密码不放行，正确密码只放行 Memo，不改变私人空间锁定状态。
- 开关随账号同步；没有私人空间密码包装时不能开启；关闭开关后可直接进入。
- UI 与文档均明确这是前端入口门禁，Memo 正文/附件仍明文存储、同步，其他既有展示/API 范围不变。
