- **定向**：负责人 2026-11-04 确认「这个风格我很喜欢，作为纸张主题完全保留」，并追加两条更正：① 侧栏结构回项目现状（不折叠、主题树与计数留在侧栏）；② 深色改中性色。
- **交付物**：[方案页](20261104-TP6-编辑器样式重构方案.html)（自包含，可切文档 / 网格 / 表格 / 专注、明暗、三种强调色、属性两态、标注）。

## 1. 判断：粗糙的不是配色，是层级

现有界面把「导航 / 清单 / 文档」做成三块同亮度、同描边的面板，文档区再纵向堆叠路径条、标题、双列属性、标签、格式栏。结果是：

| # | 现象 | 结构性原因 |
| --- | --- | --- |
| 1 | 一屏看不到几句正文 | 标题之上有 5 层常驻 chrome，正文起点被推到约 300px |
| 2 | 三块面板互相争注意力 | 三栏底色与描边同级，缺少「深度」这一维度，只能靠线分隔 |
| 3 | 阅读像在扫表格 | 14px / 672 版心 ≈ 48 汉字一行，行距 1.6，密排 |
| 4 | 工具抢内容 | 16 个图标常驻标题下方，且与正文同色同权重 |
| 5 | 换主题解决不了 | 上述问题全部属于版式与层级，换色只是换皮 |

结论：本次不调参，重建**三层表面、一套字阶、一套 chrome 收放规则**。

## 2. 方向：「纸」

- **三层表面，不删栏、不并栏**：侧栏 248（暖灰 `#EFEBDE`）→ 清单 340（浅米 `#F7F5EC`）→ 纸面（暖白 `#FCFBF6`），靠表面差与一层极淡投影成立，栏间不再用描边分隔。
- **侧栏结构完全沿用现状**（`Sidebar.tsx`）：品牌 + 折叠钮、视图切换（首页 / 笔记 / Memo）、快速输入、新建笔记、回看三格（最近 / 收藏 / 回收站）、收件箱 / 草稿箱（带计数）、加密空间、主题树（主题与分组计数）、标签、账号与版本。只改表面、间距、选中态与图标语言，**不删不并**；计数留在侧栏与清单各归其位。
- **栅格**：1440 视口 = 248 + 340 + 1fr（纸面 834）；纸面内版心 520 居中，两侧各留约 121，右侧 108 页边注。
- **页边注**：目录与关联移出正文流，落在纸面右侧 108px 边注栏（可折叠，窄屏降级为抽屉）。
- **属性两态（负责人 2026-11-04 更正）**：
  1. **侧栏（默认）**：属性随目录、关联进入页边注，正文区最干净；
  2. **顶部**：属性回到标题与正文之间，两列键值 + 浅底块（无框线、无分隔线），侧栏只留目录与关联。
  两态共用同一份数据与编辑浮层，差异只在容器与列宽（108 单列 / 520 两列）。
- **字阶**：标题宋体 40、引言 17.5、正文 17 / 1.85 / 520 版心（约 30 汉字一行）、二级标题宋体 23 带上短横线、三级 17 加粗；元信息等宽 10–11。
- **工具下沉**：格式栏从标题下方改为纸面底部 44 高悬浮坞，选区浮条负责行内格式，斜杠菜单负责插入；顶部 header 只留路径与保存状态。
- **表格编辑模式**：纸面内保留标题与工具条（字段/行数、筛选、排序、分组、添加字段、切换为笔记），表头 38、行 44、行号列 44；字段类型用图标标注，状态与优先级用胶囊，选中行浅强调底 + 2px 左条，编辑单元格 1px 强调环 + 光标。
- **色彩**：暖纸 `#FCFBF6`、清单 `#F7F5EC`、侧栏 `#EFEBDE`、墨 `#1A1B18`、松烟 `#2E5B4C`（可换赭石 / 靛青）；朱砂仅用于未保存与删除，荧光黄仅用于标记。
- **深色（中性）**：四个表面改为中性灰 `#262624` / `#20201E` / `#1B1B1A` / `#161615`，墨 `#EAEAE7`，不带绿或橄榄偏色；强调色只出现在图标、选中条、状态胶囊等小面积元素，主按钮在深色下改为中性亮面（`#E7E5DC` 底 + 深字），避免整块浅绿造成视觉不适。

## 5. 验收标准

1. 1440×900 下，纸面顶端到正文首行 ≤ 240px；标题之上无第三条横线。
2. 正文行宽 29–31 汉字，行高 1.85；二级标题上下间距 38 / 14。
3. 侧栏条目、顺序、计数位置与现状一致（品牌 / 视图切换 / 快速输入 / 新建 / 回看 / 收件箱草稿 / 加密空间 / 主题树 / 标签 / 账号）。
4. 属性两态可切换：顶部形态块宽 520、两列键值，与标题间距 24；切回侧栏时正文版心不位移。
5. 表格：6 列在 834 纸面内不横向滚动；行高 44；编辑单元格有 1px 强调环与光标。
6. 深色下四个表面为中性灰，明度差 ≥ 3%，无绿/橄榄偏色；强调色只出现在小面积元素。
7. 全部取值走 token；`src/shared/test/structure.test.mjs` 通过；`pnpm -r typecheck` 与 web 测试全绿。

## 6. 已知代价与风险

- **单行字数由 48 降到 30**（约 −37%）：三栏保留后纸面只有 834，520 版心是能容纳 108 页边注的上限。长文滚动明显变多，这是换取书籍式阅读节奏的自觉取舍；若负责人认为密度过低，可把边注改为抽屉、版心放宽到 600。
- **宋体标题依赖**：CJK 衬线在部分 Android / 旧 Windows 回退到系统宋体，字重偏细。需自托管 Noto Serif SC 子集（300–500KB）或接受回退。
- **底部坞的可发现性**：首次使用可能找不到加粗，需首启提示 + 斜杠菜单暴露快捷键。
- **改动面大**：tokens 重命名会波及全部样式文件，建议单独一次提交做机械映射。
- **「阅读宽度」设置项失效**：固定 520 + 边注后三档宽度无处安放，应同步下线，避免「设了没用」。

## 8. 墨台 v3 完成态视觉模板补充（2026-11-05）

墨台（INKSTAND）作为独立视觉语言继续完善；此补充属于设计模板，不表示下述交互已在 `src/` 实现。可交互样例见 [`design-v3/index.html`](design-v3/index.html)。

### 8.1 明确产品状态

- 本地保存与云端同步分开表达：`保存中`、`已保存到本机`、`等待同步`、`同步失败`、`已同步`。离线可继续编辑；失败保留本机内容并提供可见重试入口，不用“已同步”代替本地保存确认。
- 加密锁定态隐藏正文、属性值、摘要、附件预览与检索片段。只显示可见性规则允许的标题及加密标识；锁定时不生成明文恢复副本。正文样稿标为“已解锁”，避免把可读样稿误认为锁定内容。
- 补充加载中、空清单、无搜索结果、读取失败、未保存更改及崩溃恢复提示。空数据与加载/错误状态分别呈现；未保存离页提供保存或留在页面的选择，恢复副本进入正常保存链路且不静默覆盖正文。

### 8.2 编辑器与表格行为

- Note 常驻模式严格为“编辑 / 预览”两项；源码、版本历史、加密设置、未归类笔记的整理入口收纳进“更多”，符合 FR-EDT-2/3。选区浮条、斜杠菜单、浮动大纲、A4 纸张开关、专注模式及字体颜色的完整状态按 FR-EDT-4/6/12～15 覆盖。
- 表格样例显式呈现超过可视宽度时的横向滚动、列宽调整与列顺序调整把手；表头/行号、键盘焦点与筛选状态保持可识别。拖动以外提供键盘操作入口，覆盖 FR-TBL-12、17、18。
- 所有浮层说明键盘开关、方向键/Enter、Esc 关闭及焦点返回；确认弹层限制焦点并在关闭后还原触发点。触屏提供可见等价入口；拖动任务提供非拖动替代操作与可撤销反馈（FR-IA-11/14）。

### 8.3 响应式与设置归属

- 模板标注桌面（≥1280）、平板（768–1279）、手机（<768）：侧栏/清单按任务转抽屉或单视图，纸面保持可读宽度；属性/大纲可从抽屉访问；底部工具栏避开安全区和软键盘。长表只在表格容器横向滚动，长文的纸张随内容延展。
- 明确账号级设置（主题、布局、阅读偏好）与设备级设置（如表格列宽）的归属、跨设备行为及登录状态反馈，避免把本机偏好误示为同步数据。

### 8.4 视觉验收补充

- 方案页可切换上述保存/同步、锁定、加载、空态、错误与恢复样例；每种状态必须给出状态名称、影响范围和恢复动作。
- 在浅色/深色和桌面/平板/手机样例中，检查焦点环、文本截断、横向滚动、抽屉遮挡、安全区、减少动态效果；状态色不能作为唯一含义载体。
- 正文与常规字号文字对比度至少 4.5:1；大字及关键图形控件至少 3:1；焦点环相对相邻表面清晰可见。浅/深表面上的弱化文字也按正文对比度检查。
- 墨台继续作为版式与交互体系，不将本补充视为代码实现或版本升级。实现前仍需将每个功能映射到需求条目并按对应计划验收。
- 首页统计只展示已有本地数据可可靠计算的数量并标明周期；原型中的数字是展示样例，不定义新的行为追踪。加密锁定时不显示摘要或内容长度。
