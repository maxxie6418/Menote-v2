## 2026-11-02：第四批（属性区、格式栏吸顶、加属性跳页尾）

- **来源**：负责人反馈三处——① 顶部属性区显示不对（键名被截成 `pa…`、值只露半截）；② 格式栏随文档一起滑动，没有真正吸住；③ 添加（属性）后页面直接跳到页尾。
- **① 属性区**：根因是两列栅格 + `--app-prop-key-width: 30`——外部剪藏进来的键是 `parent_url` / `clipped_at` 这类长键，30px 只能显示 `pa…`，值输入框也被挤成半截。改为**单列**，键名列 120px（`--app-prop-key-width: 7.5rem`），值吃满剩余宽度并保留行尾 ×；行高改 `min-height` + 上下内边距，长值不挤压。DESIGN §4 属性行同步为「单列、键名 120px」。
- **② 格式栏吸顶**：`position: sticky` 本身生效，但 `top: 0` 是相对滚动容器的**内容盒**，于是常驻位置比文档栏低 34px（`.mn-docbody` 的 padding），正文从工具栏上方露出来，看着像"跟着一起滑"。改为 `top: calc(var(--app-doc-pad) * -1)`，吸住时贴着文档栏底边、正文从它下面穿过。
- **③ 加属性跳页尾**：`setSelection` 的 markdown 偏移→ProseMirror 位置映射有 bug——`descendants` 回调里 `return false` 只表示不深入子节点、**不会中断遍历**，`found` 被后续每个文本块反复覆盖，最终总落在文末，`scrollIntoView()` 于是把页面滚到底。改为记录第一个覆盖该偏移的文本块并按块内字符数取位；同时给外部写回（属性增删、他端变更）加 `keepScroll`：`replaceAll` 前后锁住 `.mn-docbody` 的滚动位置，layout 后再兜一次。
- **顺带**：新增 `MilkdownWysiwygAdapter.activeMarks()`，格式栏按下态改读编辑器选区（含空选区的 `storedMarks`）——此前只看 markdown 偏移，光标处按 B 时按钮不会亮，看着像"没生效"。与并行提交 `1ca85f5`（格式动作改走原生 `applyFormat`）互补，不重复。
- **验证**：`pnpm --filter @menote/web typecheck` 通过；静态渲染核对属性区 5 行长键全部可读、格式栏滚动 300px 后贴住文档栏底边、正文从其下方穿过。真实 Markdown/剪藏文档的端到端仍需浏览器走查。

## 2026-11-02：第六批（表格网格线、图片上传、设置·样式编辑器）

- **来源**：负责人反馈三条——① 加表格后网格线不清晰，无法确认格子边界；② 图片添加后直接裂开，需要上传进度条且要能正常显示；③ 设置里要有样式编辑器（各级标题与加粗的字号/颜色/粗细/装饰下划线）。确认「下划线」指标题下方的**装饰分割线**（比文字略长、与标题同体），样式**全局一套**。

### ① 表格网格线

- 根因：编辑器里 `th/td` 只画了底边（`border: 0; border-bottom: …`），纵向完全没有分隔，新插入的 3×3 表格看起来是一片文字；`--md-table-cell-pad` 还把左边距设成 0。
- 改法：单元格四边统一 `--md-table-border`、内边距换 `--md-table-padding`、表头补 `--md-table-head-bg` 底色、外层 table 加边框，并补上 prosemirror-tables 的 `.selectedCell` 高亮——否则拖动选区看不出选中了哪几格。DESIGN §3.3 补一条网格线规则。

### ② 图片裂图 + 上传进度

- **裂图根因（后端）**：`attachmentRoutes.use("/api/attachments", resolveSession)` 只匹配这一个精确路径，而读取/删除都在 `/api/attachments/:sha256`。子路径没跑会话解析，`requireSession` 拿不到 `authUser` → 一律 401。上传是精确路径 POST，所以表现为"能上传、看图全裂"。修成与 `clip-templates` / `mcp/tokens` 一致的 `/*` + 基础路径双挂载。
  - 对照验证：把 `/*` 那一行去掉重跑新测试，GET 断言立刻变成 `expected 200 / actual 401`；恢复后通过。
- **进度**：`uploadAttachment` 从 `fetch` 改为 `XMLHttpRequest`（fetch 没有上传进度），带 `onProgress(0–100)`；编辑器底部新增 `.mn-uploadstack`，逐文件显示「文件名 · 百分比 · 进度条」，失败留一行红字并可点 × 忽略。进度条用原生 `<progress>`（结构门禁禁止内联 style，百分比只能交给元素自身），`::-webkit-progress-*` 走 token 上色。
