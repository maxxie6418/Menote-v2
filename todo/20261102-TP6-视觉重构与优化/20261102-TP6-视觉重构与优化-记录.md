### 改了什么

**弹窗（7 处统一）**

- `tokens.css` 新增 `--app-dialog-width-md/lg/xl`（480/640/864）与 `--app-dialog-max-height`（`100dvh - 48`）；删除旧的 `--app-dialog-wide`。
- `.mn-overlay` 改 `display: grid; place-items: center; padding: 24; overflow-y: auto`；`.mn-dialog` 去掉 fixed + translate 居中，改 `max-height` + `overflow: hidden`。
- 新增 `.mn-dialog-head` / `.mn-dialog-body` / `.mn-dialog-actions` 三段：头部与操作行固定，中段自身滚动；操作区允许换行，主按钮不再 `flex: 1`。
- 改造位置：`EncryptDialogs`（恢复码、启用单篇加密）、`NoteDocument`（导出）、`OrganizeDialog`、`TableBlockDialog`（空态与宽态）、`HistoryPanel`。设置对话框沿用自有的 `.mn-dlg-head/body`，只把宽度与高度改成 `min(…)` 以免小窗口溢出。

**编辑器与文档区**

- 新增 `--app-doc-measure`(42rem) / `--app-doc-measure-wide`(56rem) / `--app-doc-title-size`(2.25rem)；`.mn-docbody > *` 统一 `max-width` + 居中，`data-form="table"` 时放宽。
- `.mn-docbody` 从 flex 列改回常规流（`> * + *` 间距），`.mn-editor-host` 不再自滚——单滚动容器，格式栏 `sticky` 才成立。
- 标题 32 → 36，并给 `.mn-doc-title + *` 留 18 间距；`.mn-doc-title` 补 `display: block` 让自动外边距生效。
- 预览补 `markdown-content` 类（`NoteDocument` / `EncryptedNoteView`），恢复此前完全缺失的 md 排版。
- 格式栏：`FormatBar.tsx` 改为图标映射（16 个 lucide 图标，中文进 `title`/`aria-label`），`.mn-formatbtn` 24×24 网格、选中态改橙底、补聚焦环；移动端单行横向滚动 + 44 触控目标。

**表格页**

- 新增 `.mn-tabledoc-bar`：字段数/行数（等宽数字）+ 添加字段 + 切换普通笔记；`TableDocument.tsx` 同步。
- `.mn-tabledoc-scroll` 加 `max-height: 62dvh` 并自身滚动，表头 `sticky` 生效。
- 行号列 30 → 46（`--app-tabledoc-rownum-width`），容纳拖拽手柄/序号/删除；行删除由 `×` 字符改 `Trash2` 图标；字段类型徽标改胶囊描边。
- 单元格最小宽统一到 `--app-table-cell-min`（7.5rem），6 列在 896 版心内不再横向滚动。

**滚动条**

- `.mn-dialog-body`、`.mn-tabledoc-scroll` 登记进 `scrollbar.css` 的 `scrollbar-gutter: stable` 清单；`shell.css` 里的临时声明删除，保持单一出处。
- 说明：滚动条样式本就是 `*::-webkit-scrollbar` 全局接管，无需逐容器挂类；本轮只是把新增滚动区纳入槽位预留，避免出不出滚动条时内容横跳。

**文档**

- `DESIGN.md` §5.1 补"版心 672 / 表格 896"约定，§5.2 对话框改为按档位描述。
- `todo/PLAN.md` 登记 TP6 与并行收尾状态。
