# TP3 · 剪藏模板规则库设计

- **创建日期**：2026-11-01
- **状态**：已确认，进入实施
- **范围**：EdgeEver 规则转存、Menote 模板契约、插件本地同步缓存、网页可视化模板制作、Menote 设置管理。
- **关联需求**：FR-EXT-2、FR-MCP-2/6/10；规则读取/写入不属于笔记正文读取权限。

## 1. 目标与不变量

EdgeEver 新增剪藏优化时，由导入工具把可表达的规则转存为 Menote 自己的版本化模板快照。转存后的规则保存在 Menote 当前用户的模板库中，运行时不再读取 EdgeEver 仓库或依赖其模块；上游删改不会影响已保存模板。复杂页面无法安全转成声明式规则时，保留独立代码适配器或通用 Readability 路径。

- 主应用设置中的 Menote 模板库是权威副本；插件本地只存最近成功同步的缓存。
- EdgeEver 导入器与网页可视化制作器产出同一个声明式模板 schema。
- 模板只能表达域名/路径匹配、CSS 选择器、字段取值、排除列表和内置 Markdown 转换；不允许任意 JavaScript、`eval`、动态导入或网络请求。
- 插件应用顺序：黑名单过滤副本 → 已同步且启用的站点模板 → Schema.org / Readability / 主内容文本 fallback。
- 没匹配模板、模板失效或执行失败时回到通用剪藏，不阻断剪藏。
- 模板同步/写入权限与 `content:read` 分开；关闭笔记内容读取不能阻止模板同步或新模板保存。
- 已删除/停用模板在下一次成功全量同步后从插件缓存移除；同步失败时保留最后一份可用缓存。

## 2. 稳定模板契约（v1）

运行时模板示例：

```json
{
  "schemaVersion": 1,
  "id": "uuid",
  "name": "Example Article",
  "enabled": true,
  "match": {
    "hosts": ["example.com", "www.example.com"],
    "paths": ["/article/*"]
  },
  "selectors": {
    "title": { "selector": "article h1", "value": "text" },
    "content": { "selector": "article .content", "value": "html" },
    "author": { "selector": ".byline", "value": "text" },
    "publishedAt": { "selector": "time", "value": "attribute", "attribute": "datetime" }
  },
  "exclude": [".ad-slot", ".related-articles"],
  "source": {
    "kind": "edgeever",
    "repository": "tianma-if/edgeever",
    "commit": "<fixed-commit>",
    "path": "apps/extension/src/example-clip.ts",
    "license": "AGPL-3.0"
  }
}
```

契约校验采用硬上限：单模板最大 48 KiB、最多 16 个 host、32 个 path、32 个排除选择器；selector 长度不超过 512 字符。host 必须为规范主机名，不接受 scheme、凭据、端口或通配符；path 使用以 `/` 开头的简单 `*` 通配，不接受任意正则。字段值仅允许 `text`、`html`、`attribute`，attribute 仅允许 `datetime`、`content`、`href`、`src`、`alt`。所有选择器在接受前编译验证。

存储记录另有 `version`、`updatedAt`、`sourceKind` 与导入摘要。规则中保留上游仓库、固定 commit、源文件和许可证，保证转存快照可追溯。

## 3. 规则来源与制作流程

### EdgeEver 转存工具

- 输入固定 commit 中的站点适配源文件。
- AST 工具抽取简单的 URL host/path 条件、DOM selector 与可识别的字段读取，生成 Menote schema JSON；输出报告列出成功映射与未识别逻辑。
- 生成物默认为停用/待审状态；在 Menote 设置导入、预览并确认后启用。
- 点击展开、跨接口取数、复杂身份/状态判断、站点交互和非确定性转换不能假装被转译。转译报告必须标明“不支持”并建议保留代码适配器。
- 转译完成后结果是独立数据快照，不在浏览器端引用上游 TS 文件；以后 EdgeEver 删除规则不会删除 Menote 已转存版本。

### 网页可视化制作器

- 用户从扩展弹窗启动“制作剪藏模板”；内容脚本在页面顶层使用隔离 overlay 标出当前 hover 节点，不改动网页内容。
- 用户依次选择标题、正文、可选作者/发布时间节点，并点选要排除的广告/导航/推荐节点。
- selector 生成优先使用稳定 id、语义标签和稳定属性；避开随机 class。显示选择器和命中数，可撤销，并在过滤后的副本中预览 Markdown。
- 校验通过后通过 MCP `save_clip_template` 保存到用户模板库并立即写入插件缓存。之后可在 Menote 设置中编辑、停用或删除。
- 模板只保存选择器和转换方式，不保存当前网页文本、DOM 快照或任何页面凭据。

## 4. Menote 权威存储与权限

- D1 新增按 `user_id` 隔离的 `clip_templates` 表，保存模板 JSON、启用状态、版本号、来源元数据、创建/更新时间及删除标记；SQL 只在 `db/clipTemplates.ts`。
- Worker 在 `routes/clipTemplates.ts` / `services/clipTemplateService.ts` 提供已登录用户的列表、导入、编辑、启停和删除；所有查询包含 `user_id`。
- 设置对话框新增「剪藏模板」页，可查看来源、版本、匹配规则、启停、编辑/导入 JSON 和删除，并通过当前模板在内置验证样本/页面结构检查后启用。
- MCP 新增 `clip:templates:read` 与 `clip:templates:write` 两项独立 Token 权限。前者仅能同步启用模板；后者仅能新增/更新用户自己的规则。模板权限不授予项目条目读取，且不受笔记范围/Memo/includeMemos 控制。
- MCP tool list 按最新 Token 权限动态返回 `list_clip_templates` / `save_clip_template`。保存写操作记录模板 ID 与操作结果，不记录网页内容。
- 每个 MCP 请求仍重新读取当前 Token 权限；降权和撤销对下一次调用生效。

## 5. 插件缓存与运行流程

- 缓存 key 为 `captureTemplates.v1`，包含 schemaVersion、完整模板快照、同步时间和服务端 SHA-256 revision；仅写入 `chrome.storage.local`，内容脚本不直接读取 storage。
- 弹窗打开时若缓存过期（默认 15 分钟）尝试同步；提供手动“同步规则”。捕获时仅使用最近成功的缓存，不因网络离线阻塞。
- 同步响应先完整校验所有模板，再原子替换缓存；任一模板、响应结构、网络或鉴权错误都保留旧快照并显示状态。
- 缓存只包含当前用户启用模板；全量快照替换自然移除项目中已停用或删除的模板。
- 在捕获副本中按精确 host 与 path 匹配，按 exclude selectors 删除元素，然后提取 title/content/metadata 并调用共用 Turndown；模板结果包装为既有 `CaptureResult`，后续 MCP `clip_page` 路径不变。
- 无权限且无缓存时只运行通用 fallback；有缓存但暂时无权限时可继续离线使用缓存，并提示需恢复授权后同步。

## 6. 模块接缝

```text
EdgeEver AST importer ─┐
                       ├→ ClipTemplateV1 → Menote D1 / Settings manager
Page visual editor ────┘                         │
                                                 └→ MCP template tools
                                                        │
                                                        ▼
                                              Extension local snapshot
                                                        │
                                                        ▼
                                        template adapter → CaptureResult
                                                        │
                                                        ▼
                                          generic fallback / MCP clip
```

Worker 仅依赖 shared 契约，不依赖扩展 UI；扩展仅经 MCP 读取/保存模板；模板引擎只依赖 schema 和文档副本，不依赖 EdgeEver。工程结构设计登记 Worker 模板存储/服务、设置管理面与扩展声明式模板执行器。

## 7. 验收

1. EdgeEver 简单站点源文件能生成独立 JSON 快照；重新构建/运行不访问 EdgeEver。未支持的动态逻辑清晰列在转译报告。
2. 用户在设置中可导入、预览、编辑、启停和删除自己的模板；不同账号模板完全隔离。
3. Token 仅有 `clip:templates:read` 时可同步模板但读不到既有笔记；仅有 `clip:templates:write` 时可保存模板但不能列举模板或读笔记；权限变更下次请求立即生效。
4. 插件成功同步后写入本地缓存；之后断网仍可使用；删除/停用服务器模板后同步成功会清除旧缓存。
5. 可视化制作器能选标题/正文/元数据、排除元素、预览并保存；原网页 DOM 不变化；恶意 CSS selector / 脚本字段被拒绝。
6. 模板命中时使用模板格式；不匹配/损坏/提取空时回落 Readability；现有 MCP 剪藏收件箱和 YAML 数据流不变。
7. browser-extension 与 Menote Worker/Web 类型检查和构建通过；文档、MCP 权限和结构清单同步更新。
