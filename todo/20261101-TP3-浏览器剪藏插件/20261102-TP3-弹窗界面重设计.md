## 1. 目标

把弹窗从「一根长条 + 6 个平级按钮 + 内嵌折叠设置」改成三级结构：主界面、独立预览页、设置页。主界面只留两个平级操作（收藏网址 / 剪藏此页），状态用一枚只读 chip 呈现（收藏与剪藏不同时显示），站点规则收进折叠区。

## 2. 需求清单（已与负责人确认）

| # | 需求 | 说明 |
|---|---|---|
| R1 | 一键剪藏 | 点「剪藏此页」内部完成提取与写入，不强制进预览；每次点击新建文档，已剪藏不拦截 |
| R2 | 收藏不依赖提取 | 现状已满足，收藏只读 DOM 元数据 |
| R3 | 状态 chip | 一枚状态 chip + 一枚规则 chip，全部只读。状态 chip 只显示最重的动作：已剪藏 > 已收藏 > 未保存；两者都有时只显示剪藏，附上次剪藏时间 |
| R4 | 网页规则折叠区 | 制作当前网页规则、检查规则更新；原整行「同步剪藏模板」按钮取消 |
| R5 | 独立预览页 | 新标签页打开，Markdown 可编辑，剪藏提交编辑后的文本 |
| R6 | 设置页 | 域名 / Token / 收藏目标 / 能力测试五行；**测试与保存是两个独立按钮**，测试只做只读校验、不写配置，保存只写配置、不自动测试。测试含「网络延迟」（`connect + listTools` 往返毫秒，按 <500 / <2000 / ≥2000 三档着色）；剪藏与收藏成功提示也会带上真实写入耗时 |
| R7 | 图标角标 | 页面已收藏或已剪藏时，工具栏图标显示状态角标（见第 7 节） |
| R8 | 标签与备注 | 打开弹窗即可填写，收藏与剪藏都带同一份；可留空直接提交，一次点选完成（见第 6 节） |

## 3. 主界面

```
┌──────────────────────────────────────────────────┐
│  ◈  Menote 剪藏    ●已连接 [⌂ note.x]  ☀  ⚙  │
├──────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────┐  │
│  │  sspai.com                                 │  │
│  │  为什么我们重新设计了阅读体验              │  │
│  └────────────────────────────────────────────┘  │
│  ┌────────────────────┐ ┌────────┐                │
│  │ ✓ 已剪藏·2 小时前  │ │⚡命中  │                │
│  └────────────────────┘ └────────┘                │
│  ┌────────────────────────────────────────────┐  │
│  │ 标签  [阅读] [产品] [+ 添加标签]           │  │
│  │ 备注  [____________________________]       │  │
│  └────────────────────────────────────────────┘  │
│  ┌──────────────────┐┌──────┬──────────────────┐ │
│  │    ☆  收藏网址   ││  👁  │   ⭳  剪藏此页    │ │
│  └──────────────────┘└──────┴──────────────────┘ │
│  ┌────────────────────────────────────────────┐  │
│  │ ▸  网页规则                 命中「少数派」▾│  │
│  └────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────┤
│  提示条（无内容时不占高度）                      │
└──────────────────────────────────────────────────┘
```

- 固定 **360 × 560**：宽度不随内容变化（长标题用省略号截断，grid 列用 `minmax(0,1fr)` 与 `min-width:0` 兜住 nowrap 文本）；内容超出高度时只在内部滚动，窗口尺寸恒定。
- 头部右侧依次是：**项目主页按钮**（品牌色醒目，显示已配置的主域名，点击新开标签打开该实例）、**深浅色切换**、**连接设置**。深浅色存本地 `menoteUiTheme`，默认深色。
- 复合按钮总宽 198px：眼区 40px + 1px 分隔线 + 剪藏区 157px，眼区约占 20%。眼区透明底、hover 浮出浅色块与 tooltip「预览并编辑」；两块独立命中。
- 两操作互不阻塞：收藏进行中不禁用剪藏，反之亦然。
- 状态 chip 一枚，只显示最重的动作：已剪藏 > 已收藏 > 未保存；两者都有时不叠加，直接显示剪藏及其时间。命中模板 / 通用提取是第二枚 chip。
- 「剪藏此页」文案在任何状态下都不变：已剪藏后再点仍是「剪藏此页」，结果是新建一篇文档；成功后保留底部绿色提示条。
- 标签与备注区视觉权重低于主操作：12px 字号、浅底、单行高度合计约 62px，放在页面卡与操作按钮之间，填完直接点按钮，不经过任何二级确认。
- 标签输入支持「输入后回车生成 chip」与「退格删除最后一个」，点 chip 右侧 × 移除；备注为单行输入。两者都可留空。

## 5. 独立预览页

```
┌────────────────────────────────────────────────────────────────┐
│ ◈  Menote 剪藏预览              为什么我们重新设计了阅读体验 ☀│
├────────────────────────────────────────────────────────────────┤
│ 模板「少数派」 · 6,482 字 · 3 张图 · 14:20 提取      [重新提取]│
├────────────────────────────────────────────────────────────────┤
│        ┌──────────────────────────────────────────┐            │
│        │ 标签  [阅读] [产品] [+ 添加标签]         │            │
│        │ 备注  [____________________________]     │            │
│        ├──────────────────────────────────────────┤            │
│        │ # 为什么我们重新设计了阅读体验           │  ← 42rem  │
│        │ （可编辑 Markdown，等宽 13/1.85）         │   居中列  │
│        │                                          │            │
│        ├──────────────────────────────────────────┤            │
│        │ ▸ 页面属性（折叠）                       │            │
│        │   站点 / 作者 / 时间 / 摘要 / 原文 / 提取器           │
│        └──────────────────────────────────────────┘            │
│                                                                │
│ [ 复制 Markdown ]  [ 重新提取 ]          6,482 字 [ 剪藏 ] ●  │
└────────────────────────────────────────────────────────────────┘
```

- 打开方式：`chrome.tabs.create({ url: "preview.html?tabId=<id>&page=<url>" })`，与 `template-editor.html` 一致。正文不进 URL。
- 预览页自行注入 `content.js` 取正文，不依赖 popup 状态。
- **正文列宽固定 42rem（672px）居中**，与 Menote 编辑器的 `--app-doc-measure` 一致；顶栏、元信息条、底部操作条通栏，但内容按同一列宽对齐。
- 页面属性收在折叠块里，只列 `CaptureResult.metadata` 实有字段（站点、作者、发布时间、摘要、canonical）+ 提取器标识，不虚构封面、标签。
- 提交的是编辑后的文本，修掉现状 `#markdown` 带 `readonly` 且发送原提取内容的问题。
- 标签/备注在编辑区上方，是用户补充字段，不是提取结果；从弹窗带入时保持一致，可在预览页修改后随剪藏一起提交。
- 深浅色跟随弹窗里存的 `menoteUiTheme`，右上角可就地切换。

## 6. 标签与备注

负责人 2026-11-02 补充：希望像 Raindrop 一样给网页打标签、写备注，并且**一次点选就能完成**，不要先填、再点、再补填。所以这两个输入框在弹窗打开时就可见，收藏与剪藏共用同一份内容，也可以完全留空直接提交。

### 6.1 交互

- 打开弹窗即见，不折叠、不放在二级页。
- 标签：输入后回车生成 chip，退格删除最后一个，点 × 移除；本期只做自由输入，不做历史标签补全（可后置）。
- 备注：单行输入，允许空。
- 内容在同一会话内被两个操作共用：点收藏和点剪藏都带上当前这份标签与备注。
- 不做必填校验，不做提交前确认。

### 6.2 数据流

| 路径 | 契约现状 | 需要做什么 |
|---|---|---|
| 收藏 `append_bookmark` | `McpBookmarkRequest` 已有 `tags: string[]` 与 `note?: string` | 插件把输入内容填进 `BookmarkCapture` 即可，服务端无需改动 |
| 剪藏 `clip_page` | `McpClipRequest` 只有 title/markdown/sourceUrl/capturedAt/metadata | 契约加可选 `tags?: string[]` 与 `note?: string`，Worker 序列化到 YAML frontmatter |
| 预览页 | — | 打开时带入弹窗已填内容，提交时以页面上最终内容为准 |

- 标签与备注是元数据，写进 Note YAML，不混入正文 Markdown。
- 契约字段全部可选，旧插件调用旧字段不受影响；`schemaVersion` 保持 1。
- 收藏目标是表格时，标签/备注对应 Raindrop 兼容字段（`tags` / `note`），已在收藏可行性文档的字段表里列明。

## 7. 图标角标

### 7.1 现状问题（0.1.16）

`build.mjs` 已生成 `icon-*-clipped/bookmarked/both.png`，`applyActionIcon()` 也会切换，但角标是：

- 已剪藏 = 绿色实心方块（右下）
- 已收藏 = 绿色实心圆点（右下）
- 两者 = 方块 + 圆点叠加

问题：直径占 42%，48px 时压住笔记本主体；纯色块无图案语义，用户无法反推含义；形状差异在 16px 下不可辨。

### 6.2 新规范

角标位置固定在右下角，直径 40%（48px→19px，32→13，16→6）。外圈白色描边保证在任何工具栏底色上都有隔离。色 + 形双编码：

| 状态 | 形状 | 底色 | 图案 | 语义 |
|---|---|---|---|---|
| 已收藏 | 正圆 | `#2F6BFF` 蓝 | 白色五角星 | 收进收藏夹（蓝色，与品牌橙拉开对比） |
| 已剪藏 | 圆角方（r=28%） | `#19A567` 绿 | 白色对勾 | 已入库 |
| 两者都有 | 与已剪藏相同 | — | — | 剪藏优先，只显示一枚角标，不叠加 |

- 角标只有一枚：已剪藏覆盖已收藏，与状态 chip 的取值规则一致（已剪藏 > 已收藏 > 未保存）。
- 16px 时图案退化为纯色，靠形状与颜色区分；32/48/128 保留图案。
- 主体图标保持原样，不缩放，避免与角标重叠压缩。
- **角标要由后台维持**：Chrome 在每次导航后把工具栏图标重置为默认值，只在弹窗里 `setIcon()` 会「刷新就丢」。`src/background/main.ts` 在 `tabs.onUpdated` / `onActivated` / `storage.onChanged` 时按本地 `menotePageActions` 记录重打角标。

### 6.3 实现路径

- 方案 A（已采用，2026-11-02 完成）：保留 `sharp` 构建期生成，只改 `scripts/build.mjs` 的 `statusMarker()`，替换形状与配色，生成同名文件，`applyActionIcon()` 无需改动。
- 方案 B：运行时用 `OffscreenCanvas` 合成 + `chrome.action.setIcon({ imageData })`，可随时调样式，但每个 tab 每次切换都要重绘。

## 7. 数据结构变更

`PageActionState` 目前只有一个 `updatedAt`，chip 需要分别显示上次收藏 / 上次剪藏时间：

```ts
interface PageActionState {
  clipped: boolean;
  bookmarked: boolean;
  updatedAt: number;      // 保留，兼容旧记录
  clippedAt?: number;     // 新增
  bookmarkedAt?: number;  // 新增
}
```

`readPageActionState()` 对缺失字段回退到 `updatedAt`，键名保持 `menotePageActions.v1`，不做 v2 迁移。

## 10. 不做

- 服务端查询剪藏 / 收藏是否存在，只用本地记录（上限 500 条，清扩展数据即丢）
- 规则列表管理页（后续可能放进插件独立设置页）
- 弹窗内历史剪藏列表
- 收藏 / 剪藏的撤销与「再次剪藏」按钮
- 标签历史补全、标签管理、备注多行富文本（后续按需要再加）
