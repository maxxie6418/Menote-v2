## 3. 实现约束

- `@milkdown/*` 只留在 `features/editor/`。新增的选区读写放在 adapter 上，进出只有字符串和纯数据。
- 不引入新的编辑器依赖，不换 Milkdown 版本。
- 源码适配器继续用 textarea。
- 格式变换失败时正文保持原样，底栏给出不阻断的提示。
- 单文件接近 1000 行就按职责拆，不把格式栏和斜杠菜单写进 `NoteDocument.tsx`。
- 样式值走 `tokens.css`。

## 4. 验收

浏览器走查一篇带属性、表格、代码块、图片的笔记：

1. 格式栏每一项都能插入，再点一次能取消行内样式。
2. 「/」在行首弹出，在句子中间不弹出。
3. 粘贴一张图、拖入一张图，都出现在光标处，保存后 Markdown 仍是 `attachments/<sha256>--<原文件名>`。
4. 切到预览，图片、标题、列表、引用、代码块、表格与编辑态是同一套样式。
5. 从「更多」进入源码，frontmatter 还在；回到所见即所得，正文不丢。
6. 离开这篇笔记再回来，属性区还在。
7. 文档栏上看不到表格结构化编辑，也看不到版本历史、加密、源码的常驻按钮。
8. `pnpm typecheck` 与 `pnpm build` 通过。测试如果本轮按负责人要求跳过，在开发记录里写明。

与 [设计 §10](20261101-TP4-设计.md) 相同。实现中新冒出来的体验问题记入开发记录，不顺手做。

### 6.2 实现约束（追加）

- 校验层是纯函数模块，不 import Milkdown 类型；`@milkdown/*` 仍只出现在 `features/editor/`。
- 新增依赖仅限块级解析所需的 `remark-parse`（unified 生态，非编辑器依赖）；须在开发记录写明理由（对应设计冲突项 C2）。
- 性能监测默认关闭，诊断模式之外不打点、不注册 observer。
- 快照只写本地 Dexie，不进 outbox、不进同步、不进备份；加密笔记快照一律加密后落盘。
- HTML 导出不进备份链路；导出件无脚本、带 CSP。
- 排版标点只作用渲染层，源码与编辑器正文不变。
- 单文件接近 1000 行按职责拆；样式值一律走 `tokens.css`。

### 6.3 验收（追加）

1. `pnpm typecheck` 与 `pnpm --filter @menote/web build` 通过。
2. `node --test src/web/test/*.test.mjs` 全绿（新增用例在内）。
3. 浏览器走查：含属性、表格、代码块、图片、YAML 的笔记各一篇，覆盖六项可见行为。
4. 未触碰内容零改写：编辑长文并保存，版本历史里不出现纯格式噪声 diff。
5. 安全走查：快照不进同步；加密笔记快照为密文；导出 HTML 无脚本、无外部请求。
6. 性能：相对 W0 基线，编辑态与预览态耗时不劣化。
