## 1. 目标

让 Note 的写作区能按日常节奏写完一篇：格式不用记 Markdown 语法才能用，图片插在光标处并且编辑时看得见，正文样式和预览一致，离开页面不会把属性写丢。Memo 编辑器不动。

## 2. 写作区结构

自上而下，只在 Note 编辑态出现格式栏：

1. **文档栏**（固定不滚）：面包屑、返回、常驻动作、编辑/预览分段。
2. **标题**。
3. **属性区**（既有，不动）。
4. **标签行**（既有，不动）。
5. **格式栏**（固定不滚，仅编辑态）：行内与块级动作。预览态不渲染。
6. **正文**：独立滚动。编辑态为 Milkdown；预览态为既有 `MarkdownView`。

格式栏不并进文档栏。文档栏继续只放文档级动作，避免和格式按钮挤在一行。

## 3. 文档栏与「更多」

常驻，从左到右：

- 插入附件
- 导出
- 移入回收站
- 更多
- 编辑/预览分段（位置与样式不变）

「更多」菜单，顺序固定：

- 源码切换（FR-EDT-3；当前已是源码时文案为「回到所见即所得」）
- 版本历史
- 启用单篇加密（已加密的笔记不出现此项，加密视图不走这套栏）
- 整理到主题（仅未归类笔记出现）

**撤下，不进「更多」**：表格结构化编辑（`TableBlockDialog` 的文档栏入口）。负责人 2026-11-01 判定该入口是错误功能。WYSIWYG 内的 GFM 表格仍可直接编辑；`type: "table"` 整页网格（TP2）不在本包改动。弹窗组件本身本包不删，只去掉 Note 文档栏入口，避免半截重构；是否删除组件留后续确认。

## 4. 格式栏

一条横栏，编辑态常驻，预览态不出现。按钮分为两组，中间留分隔：

**行内**：加粗、斜体、删除线、行内代码、链接。

**块级**：标题（H1–H3，一个按钮带三级菜单）、无序列表、有序列表、任务列表、引用、代码块、分隔线、表格、图片。

行为：

- 作用于当前选区；无选区时作用于光标所在块，行内标记包住一个空位并把光标放进标记内。
- 链接无选区时插入空链接并把光标放在链接文字处；有选区时把选区变成链接文字。地址先用空占位，不弹窗。
- 选区已经是该样式时，按钮呈按下态，再点一次取消。这替代原 FR-EDT-4 的选中浮条：选中后不另弹浮层。
- 表格插入一个 3×3 的空 GFM 表（含表头），插在光标所在块之后。
- 图片与「插入附件」走同一条上传，区别只在插入位置：格式栏插到光标处，文档栏的附件按钮同样改为光标处（不再追加到文末）。
- 所有按钮有 `aria-label` 与 `title`；当前样式用 `aria-pressed`。

样式集本包固定为上面这些，不再扩展下划线、高亮、对齐。

## 5. 「/」菜单

在正文行首输入 `/`，或在空段落任意位置输入 `/`，打开与格式栏同内容的菜单：行内五项、块级九项（标题按 H1–H3 分列）。

- 继续输入做前缀过滤（按中文标签：加粗、标题、代码块、表格、图片等）。
- `Esc` 关闭并保留已经输入的 `/` 文字；`Enter` 执行当前项；上下键移动。
- 执行后删掉触发用的 `/` 及其后的过滤文字，再插入对应 Markdown。
- 不在行中弹出，避免和正常用字里的斜杠冲突。
- 菜单挂在光标附近，超出正文底部时向上翻。

与格式栏重复是有意的。两套都出全量，后续再决定留哪一套。

## 6. 图片

- 入口三条：格式栏「图片」、文档栏「插入附件」、「/」菜单「图片」。粘贴图片、把图片文件拖进正文，与这三条同等，都插到光标处。
- 一次只处理一个文件；多文件按选择顺序依次插入，每个一段。
- 非图片文件仍走附件引用，使用同一相对路径，不用图片语法。
- 编辑态必须能显示已插入的图片：`attachments/<sha256>--<原文件名>` 在喂给编辑器前解析为鉴权 URL，序列化回 Markdown 时还原成相对路径。预览态继续用 `MarkdownView` 现有解析。
- 上传失败沿用文档栏现有的不阻断错误提示，不插入半截引用。
- 大小限制沿用现有附件上限，本包不另定。

## 7. 源码模式

- 只从「更多」进入，不占文档栏常驻位，不构成第三种模式（FR-EDT-2/3）。
- 切换前先按正文拼回 frontmatter 再落盘，再换适配器。
- 源码态仍是现有等宽 textarea，不引入 CodeMirror。
- 源码态不显示格式栏，也不启用「/」菜单。
- 所见即所得创建失败时的回退保持现状（自动落到 textarea），但失败要在底栏给出可见提示，不只打 console。

## 8. 样式对齐

编辑态正文与预览共用 `--md-*`，本包对齐这些元素的字号、行高、间距、颜色：正文段落、H1–H3、有序/无序列表、任务列表、引用、行内代码、代码块、分隔线、链接、表格、图片。

- 不新增字号档位，不改 DESIGN.md 的 14px / 行高 1.78。
- 选区、占位、任务复选框这些 Milkdown 默认外观改到 `--md-*` / `--app-*`，不留浏览器默认样式。
- 编辑态与预览并排对照一次（同一篇语料），差异记在开发记录；本包不追求像素级相同，要求同一元素看不出两套字体或两套间距。

## 9. 三件附带修复

1. **卸载保存不得丢掉 frontmatter。** 现在离开笔记时直接把编辑器里的纯正文交给 `saveItemContent`。有属性的笔记会把 YAML 写掉。卸载、加密前取正文、插入附件三条路径都先拼回 frontmatter 再保存。
2. **编辑态图片可见。** 见 §6。
3. **粘贴与拖入插到光标处。** 见 §6。拖入时正文区给出可辨别的落点状态，松手即上传；取消拖拽不改内容。

## 10. 明确不做

- Memo 的编辑器、浮条、字数、插图（FR-MEMO-4 保持原样）。
- 常驻格式栏以外的选中浮条。
- 大纲、双向链接、焦点模式、分屏、打字机模式。
- 代码高亮、代码块复制按钮、语言标签。
- 设置页里的渲染样式编辑（FR-STYLE-2，M4）。
- 键入延迟与滚动帧率的量化基线（开放项 #14，留 M3）。
- 删除 `TableBlockDialog` 组件、改 TP2 整页表格。
- 快捷键规格表。本包只保证格式栏按钮和「/」菜单可键盘操作；Markdown 输入规则（`# ` 成标题等）沿用 Milkdown 已有行为，不另写一套。

## 11. 模块边界

- 新组件放在 `features/editor/`：格式栏、斜杠菜单、图片地址在编辑器内的解析与还原。
- `features/notes/NoteDocument.tsx` 只负责把栏和菜单装上、把文档栏按钮收进「更多」、调用既有上传与保存。不在 notes 里写格式变换。
- `@milkdown/*` 仍只出现在 `features/editor/` 内。格式栏不读取 Milkdown 类型；选区读写通过 adapter 上新增的纯数据方法，方法返回 Markdown 字符串与选区描述，不把编辑器类型传到 notes 或 services。
- 样式只加 token 引用，不在组件里写死色值、字号、间距。新增 token 进 `tokens.css`。
