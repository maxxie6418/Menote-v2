## 1. 目标与范围

为正式笔记清单与主题/分组树补齐上下文操作，让常用管理动作可在目标项上直接发起。

- **主题**：重命名、软删除、新建分组。
- **分组**：重命名、软删除。
- **笔记/表格条目**：移动到主题（分组可选）、加入/取消收藏、移入回收站。
- 菜单支持鼠标右键及键盘上下文菜单键 / Shift+F10；Esc 或点击外部关闭；焦点清晰、具备可访问名称。
- 笔记列表中的条目提供上述操作；目录树仅对主题/分组节点提供菜单。网格布局、私人空间、Memo、回收站中的条目不属于本任务范围。

## 2. 交互与行为约束

1. 右键打开 Menote 菜单时阻止浏览器原生菜单；菜单锚定目标项，在视口边缘调整位置，不得被侧栏/清单滚动区裁切。
2. 主题/分组重命名沿用现有命名校验与服务；取消或空名称不写入。
3. 删除主题/分组前给出目标名称与影响说明，走现有软删与恢复语义，不级联硬删笔记；确认后若当前浏览位置失效，回到全部笔记。
4. 移动操作复用现有归类数据链路，主题必选、分组可选；完成后本地列表即时反映，云端同步仍由统一 outbox 链路负责。
5. 收藏项为切换动作，菜单文字随状态显示「加入收藏」/「取消收藏」；收藏范围仅 Note/表格，不含 Memo。
6. 移入回收站沿用软删语义与既有确认交互，不提供永久删除。
7. 菜单项执行后关闭菜单；操作失败须提供可理解反馈且不丢失原数据。

## 3. 实现顺序

| # | 工作项 | 产出 | 完成标准 |
| --- | --- | --- | --- |
| 1 | 梳理现有命令与视图入口 | 复用清单/网格、主题树、移动、收藏、回收站服务 | 不绕过 services，不在 UI 直接写 IndexedDB 或网络 |
| 2 | 主题/分组上下文菜单 | TopicTree 节点右键与键盘菜单 | 主题与分组动作符合 §2；替代或收敛当前选中后才出现的操作按钮 |
| 3 | 笔记上下文菜单 | NoteList 条目右键与键盘菜单 | 移动、收藏切换、移入回收站均可用；点击条目仍保持原有打开行为 |
| 4 | 菜单定位与无障碍 | 菜单开合、焦点管理、视口边界、Esc/外部点击 | 键盘可完成打开、移动焦点、执行、关闭；不被滚动容器裁切 |
| 5 | 规格与验收记录 | 本记录、总计划、体验线计划/记录 | 记录实现范围、验证结果和未完成项 |

## 4. 工程约束

- 优先扩展既有 `features/tree/TopicTree.tsx`、`features/notes/NoteList.tsx`、`NoteGrid.tsx` 与现有服务/对话框；若确需新建共享菜单模块，先登记至工程结构设计。
- UI 通过 services 操作数据；禁止组件直接访问 IndexedDB、网络或加密材料。
- 样式使用 `tokens.css` 中的 design tokens；shadcn/ui 变更只在 `components/ui/` 与 tokens 层。
- 单文件接近 1000 行时按职责拆分；不把菜单状态塞进 AppShell 形成巨型组件。
- 只使用可丢弃测试数据。

## 5. 验收

- 主题和分组均可用鼠标右键与键盘打开菜单；所有菜单动作符合目标范围。
- 主题与分组删除均为可恢复软删，笔记内容未被级联清除；当前选中节点删除后导航状态有效。
- NoteList 可移动条目、切换收藏、移入回收站；移动后归属、收藏入口和回收站状态一致。
- 菜单在窗口边界、侧栏与清单滚动区域内可完整显示；Esc、点击外部和执行动作均能正确收起。
- 现有点击打开笔记、主题/分组选择、新建主题/分组及整理弹窗路径无回归。
- `pnpm -r typecheck` 与 `pnpm --filter @menote/web build` 通过；按负责人要求是否运行测试由执行时确认并记录。

## 6. 不在范围

- Memo、私人空间解锁流程、回收站永久删除菜单。
- 批量操作、拖拽重排、移动端长按菜单、快捷键自定义。
- 数据模型/同步契约变更、菜单视觉全面重做。
