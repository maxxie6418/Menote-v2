## 1. 目标

把 `wiki/mobile.html` 的九屏设计落成可运行的移动端界面，在 < 768px 断点接管单栏布局。

移动端不是主输入端：它承担「接替桌面未完成」与「临时速记」，查阅是主力。因此本任务包的验收重点不是功能齐全，而是**内容占满屏、输入不占位**。

---

## 2. 范围

**做**
- 单栏外壳：五格底部导航（首页 / Memo / 记录键 / 笔记 / 我的）+ 页面路由。
- 记录键与写入面板：半屏 Memo、全屏笔记、`Memo | 笔记` 切换器、切换不丢字。
- 首页、Memo（三视图 + 吸顶筛选）、笔记清单、文档、主题抽屉、我的六页。
- 已存条目的长按动作面板。

**不做**
- 平板与横屏（另开任务）。
- 已存内容的 Memo ↔ Note 转换（FR-IA-9）。
- 手机端选主题归属、属性区编辑（留给桌面）。
- 资源状态页（`wiki/monitor.html` 另有任务包）。

## 3. 交付物

| 文件 | 用途 |
| --- | --- |
| `20261101-TP1-移动端界面实现.md` | 本文件：范围、约束、验收 |
| `mobile-ui.css` | 移动端 UI 规格样式，从设计稿抽取，按组件分区 |
| `preview.html` | 样式自足性校验：只用 `mobile-ui.css` 渲染三屏 |

**`mobile-ui.css` 的定位要说清楚**：它是规格参照，不是成品样式表。

- 只用 `var(--app-*)`，不定义任何颜色/字号常量；令牌来自 `src/web/src/styles/tokens.css`。
- 尺寸按 375 标定，根容器 `.m-app` 用 `100dvh`，不写死宽高。
- 安全区用 `env(safe-area-inset-bottom)`；键盘避让留给 `visualViewport`，CSS 只暴露 `--kb` 变量。
- 落地时按 AGENTS.md §5 拆进 `features/*`，不整份塞进 `app.css`。

`preview.html` 里出现的「手机画框 / 状态栏 / 假键盘」都是预览专用，不属于产品样式——不要在实现里复制。

## 6. 验收

- [ ] 375 / 390 / 430 三档宽度无横向滚动、无内容被底部导航遮挡。
- [ ] 记录键在任何页面、任何滚动位置，位置与尺寸一致；不越界到内容区。
- [ ] 点记录键 → 半屏 Memo，键盘唤起后仍能看到顶栏与记录条。
- [ ] 切到笔记：面板变全屏，已输入内容不丢，标题留空。
- [ ] 笔记保存后进草稿箱，不弹提示、不追问归属。
- [ ] Memo 三视图切换，待办视图按 待办/进行中/已完成 分组。
- [ ] 长按条目可改状态、加标签、删除；删除后 8 秒可撤销。
- [ ] 深浅两套令牌下无颜色硬编码遗留；遮罩、面板圆角正常。
- [ ] 键盘弹起时输入区不被遮挡（iOS Safari / Android Chrome 各测一次）。
- [ ] `prefers-reduced-motion` 下记录键无缩放动效。

## 7. 风险与未决

| # | 事项 | 影响 |
| --- | --- | --- |
| 1 | 软键盘高度差异（iOS Safari 的 `visualViewport` 行为与 Android 不同） | 半屏面板的 `--kb` 需实测，不能沿用设计稿的 262 常量 |
| 2 | 五格导航每格 75px，文字 10px | 需真机核对点击准确率；不足则回落到记录键独立悬浮 |
| 3 | 已存条目只有长按入口，发现性弱 | 可考虑右侧补一个 20px 状态点作为点击目标 |
| 4 | 正文 15 / 标题 24 超出 DESIGN.md 档位表 | 若不被允许，回落 14 / 32，其余结构不变 |
| 5 | 文档选中工具条贴底浮出，与键盘可能重叠 | 需在键盘弹起时改为吸附键盘上沿 |
