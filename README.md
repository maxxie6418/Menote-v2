# Menote V2

Menote 是一款可以自己部署的本地优先笔记应用。随手记下的想法放进 Memo 时间线，需要展开时可以转成 Markdown 笔记；网页剪藏和待整理的笔记则从收件箱开始处理。编辑先保存到当前浏览器，联网后同步到自己的服务器，其他设备同步后即可接着写。

**0.4.5** 使用 Docker 运行 Web、API 和定时任务。服务器把笔记存入 SQLite，附件保存在同一个持久卷里。默认配置无需 Cloudflare 账号。

## 记录与整理

- **Memo** 适合短记录。用标签筛选时间线，按图册或待办视图回看，也可以在原卡片追加评论、引述旧记录，或把一条 Memo 转为 Note。
- **Note** 支持 Markdown 所见即所得编辑、源码和阅读预览，可按主题和分组整理。从 Obsidian 导入时，可选择整个库、文件夹或单个 Markdown 文件；笔记支持双链、嵌入、提示框和 YAML 属性。
- **多维表格** 适合整理书签、素材和清单。单选、多选和附件字段可以放在同一张表里，支持排序、筛选、批量粘贴和逐行查看详情。

同一账号里，可以把一组笔记放进私人空间，也可以只加密某一篇笔记。两者都在客户端解锁。换设备前可在原设备手动同步，并在同步状态中确认改动已上传。

## 用 Docker 启动

从仓库根目录操作。首次本机试用按以下三步完成。

1. 将 [settings.env.example](src/worker/docker/settings.env.example) 复制为同目录的 `.env`。把 `MENOTE_PUBLIC_ORIGIN` 设为 `http://127.0.0.1:8787`，为 `AUTH_PEPPER` 填入单独生成的随机密钥并妥善保存。其余设置可沿用示例值。
2. 构建并启动服务。

   ```sh
   docker compose -f src/worker/docker/compose.yaml up -d --build
   ```

3. 打开 [本机 Menote](http://127.0.0.1:8787)，按提示创建第一个管理员账号。注册默认关闭。若要检查启动是否完成，访问[就绪端点](http://127.0.0.1:8787/api/health/ready)，正常返回 `{"status":"ready"}`。

部署到服务器时，将 `MENOTE_PUBLIC_ORIGIN` 设为实际的 HTTPS 站点地址，反向代理转发到主机的 `127.0.0.1:8787`。升级或搬迁整个实例时，保留原 `AUTH_PEPPER` 和挂载到 `/app/state` 的持久卷，其中包括 `menote.sqlite` 和附件目录 `objects/`。旧 D1/R2 实例迁移前，先用旧版导出账号迁移包，再按下节导入新站。[Docker 部署与恢复说明](src/worker/docker/README.md)

## 备份与换站

在「设置 → 备份与恢复」选择备份方式。

| 场景 | 操作 |
| --- | --- |
| 保存当前账号的离线副本 | 点击「下载备份包 ZIP」。Menote 先同步本机改动，再从服务器打包笔记与附件。 |
| 把笔记迁到新站 | 登录目标账号，选择已有备份或迁移 ZIP，点击「上传并校验」。核对条目与附件数量后，点击「恢复到当前账号」。同一条目按版本合并，保留较新内容。 |
| 定时备份 | 添加 S3 兼容存储或 WebDAV 目标，选择每日、每周或手动备份。新目标默认保留 10 份，可在目标卡片调整上限。推送时优先保留完整快照，超额先清理旧的未完成记录。展开备份记录可校验或恢复。 |

账号 ZIP 上限为 256 MiB，较大的账号可使用远程快照。新站需重新配置第三方凭据，加密内容仍需原隐私密码或恢复码解锁。若要完整保留账号登录信息和服务端版本历史，请停机后备份完整数据卷，并单独保存实例密钥。

## 剪藏与外部工具

- **浏览器剪藏**支持保存网页、在阅读模式摘录，以及把选中文字存成 Memo。扩展在独立仓库维护。[Menote 客户端与浏览器扩展](https://github.com/maxxie6418/Menote-clients)
- **MCP** 可让 AI 客户端按授权范围搜索笔记、读取正文或创建条目。在「设置 → MCP 接入」创建专用令牌，点击「复制 AI 接入提示词」，将含服务地址和令牌的提示词交给要授权的客户端。手动接入使用 Streamable HTTP，端点为 `https://<实例域名>/api/mcp`，请求头为 `Authorization: Bearer <令牌>`。连接后用 `tools/list` 查看当前权限下的工具。私人空间在 MCP 中不可见，单篇加密笔记只公开标题和加密标识。
- **Raindrop** 可将收藏夹绑定到明文表格，拉取收藏，并在预览后将修改写回。
- **Workers AI** 可为明文笔记生成摘要或标签建议。管理员配置凭据后，用户可在笔记中手动调用，确认后再写入。

## 本地开发

使用 Node.js 24 和 pnpm 11.9.0。先按上文启动一个使用独立数据卷的本机开发实例，再启动前端热更新服务。Vite 会把 `/api` 请求转发到本机的 8787 端口。

```sh
pnpm install --frozen-lockfile
pnpm dev:web
```

工作区检查可分别运行 `pnpm typecheck`、`pnpm test` 和 `pnpm build`。`src/web` 包含前端与浏览器本地数据库，`src/worker` 包含 Docker 服务入口、数据访问与后台任务，`src/shared` 定义两端共用的类型与契约。
