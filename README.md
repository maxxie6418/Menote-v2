# Menote V2

Menote V2 是一款通过浏览器使用的本地优先笔记应用，将随手记录的 Memo 与适合长期整理的 Note 放在同一工作空间。内容以本地数据库为基础，可通过自部署服务在设备间同步。

项目仍在开发中，正式数据进场验收尚未完成。当前版本与工作进度以 [项目总规划](todo/20261031-M0-总体开发规划与进度总表.md)为准；上线前请仅使用可丢弃的测试数据。

## 功能概览

### Memo：随手记录

- 在时间线中快速记录和浏览 Memo，支持标签、置顶、筛选、图册及 Todo 视图。
- 为 Memo 添加评论、收藏或引述；评论与引述可在卡片内编辑，也可将 Memo 转为 Note。

### Note：写作与整理

- 使用 Markdown 所见即所得编辑、源码模式和阅读预览；选中文本后可通过快捷工具栏或右键菜单设置格式。
- 支持文档属性、附件、Markdown 表格操作、文档大纲及专注模式，并可导入 Markdown 文档。
- 用主题和分组组织笔记，支持拖动调整目录和移动笔记，以及批量移动或移入回收站。
- 提供默认与柔纸界面主题、阅读宽度和属性位置等外观设置。

### 多维表格

- 在表格中管理不同类型的字段，支持单选、多选标签及图片附件；图片可查看缩略图和原图。
- 支持行列增删、列宽调整与拖动重排、隐藏列、排序筛选、批量操作和剪贴板粘贴。
- 可打开行详情查看字段，按列选择裁切或自动换行；表格隐藏列等偏好可随账号同步。

### 数据、隐私与恢复

- 内容先保存在浏览器本地，联网后与服务端同步；支持手动同步、冲突副本和本机同步诊断日志。
- 支持私人空间和单篇笔记加密，以及回收站、历史版本、备份与恢复。
- 提供服务状态和资源监控界面，帮助查看部署与运行状况。

### 连接与扩展

- **MCP**：通过令牌授权 AI 工具访问允许的内容；私人空间和单篇加密内容受可见性规则限制。
- **Workers AI**：可启用摘要和标签建议，配置模型与每日额度；生成的概述可经确认写入笔记属性。
- **Raindrop**：可将收藏夹绑定到明文表格，拉取收藏、查看同步记录，并在预览后手动反推变更。
- **浏览器扩展**：独立仓库开发网页剪藏、划选存 Memo、阅读模式与摘录等功能。

部分功能仍需真实环境验收，尤其是备份恢复、一键部署、AI 推理、Raindrop 和浏览器扩展的端到端流程；移动端和部分交互也有待实机走查。具体范围与遗留事项详见[项目总规划](todo/20261031-M0-总体开发规划与进度总表.md)。

### 接入 AI Agent

在「设置 → MCP 接入」新建 Agent 专用令牌，点击该令牌的「复制 AI 接入提示词」，即可把服务地址、令牌和能力说明一起粘贴给 AI。手动配置时使用 Streamable HTTP 和 `Authorization: Bearer <令牌>`，服务地址为 `https://<实例域名>/api/mcp`。连接后用 `tools/list` 确认工具，调用 `connection_status` 可验证连通性。

- 开启「读取内容」后，可用 `search`、`list_items`、`list_folders` 和 `read_item` 检索、列举及读取授权范围内的内容。传入返回的 `next_cursor` 翻页。私人空间不可见，单篇加密笔记只显示标题和加密状态。
- 开启「创建条目」后，可用 `create_item` 创建明文 Note、Markdown 表格或 Memo。前两类进入收件箱，Memo 还需开启「包含 Memo」。同一次操作重试时复用原 UUID `operation_id`。
- `list_versions` 和 `read_item(version_id)` 只读取服务器 SQLite 中已有的明文历史快照。浏览器本地保存的版本历史尚无法由远程 Agent 读取。通用编辑、归属调整、表格行修改、软删除和令牌审计分页仍列在 M4。

## 本地开发

需要 Node.js 24 和 pnpm 11。生产和开发后端共用 Docker 服务器入口。先在独立数据卷启动开发实例，再使用 Vite 热更新前端。 [Docker 配置与启动说明](src/worker/docker/README.md)

```bash
pnpm install --frozen-lockfile
docker compose -f src/worker/docker/compose.yaml up -d --build
pnpm dev:web
```

Vite 把 API 代理到本机 8787 端口。工作区验证使用 `pnpm typecheck`、`pnpm test` 和 `pnpm build`。

## 部署与备份

Docker 容器将 SQLite 与附件保存在持久卷中。升级时复用数据卷与原 `AUTH_PEPPER`。账号备份位于「设置 → 备份与恢复」，支持本地 ZIP 下载与导入、S3 和 WebDAV 定时快照，以及从指定远程快照恢复。 [部署与恢复说明](src/worker/docker/README.md)
